Build the input, get the call

Change any field; the code on the right follows. Copy it, or run the same input on Apify.

TikTok usernames (tiktok or @tiktok) or profile links. Each returns the profile (followers, following, likes, videos, bio, verified, business and shop seller flags) and its latest videos.

Video or photo post links (tiktok.com/@user/video/..., short vm.tiktok.com links) or bare video IDs. Each returns the full video record, and its comments when asked for below.

Profile videos

How many of each profile's newest videos to return (up to 10), plus its pinned videos unless left out below. 0 returns the profile only.

Open each profile video for the full record: likes, comments, shares, saves, reposts, exact post time, music, hashtags, mentions, location. Off: views, caption, cover and post date only, faster.

Skip the videos a profile pinned to the top.

Only profile videos posted on or after this date (2026-11-01) or within a period (7 days, 2 weeks, 1 month).

Comments

Comments to return for each video (from the links and from profiles), most relevant first. 0 = no comments.

Replies to return under each comment that has some. 0 = no replies.

For the video links: return their comments without the video records.

Limits

Most rows per run: profiles, videos and comments together.

Monitoring

Schedule the Actor and each run returns only videos and comments earlier runs did not deliver. Profiles are returned every run, so follower counts can be tracked over time.

Guide

How TikTok Scraper works

Inputs, options and tips, from the tool's own documentation.

Profiles, videos and comments from TikTok in one Actor. Paste usernames or video links and get followers, likes, views, shares, saves, music, hashtags and the exact post time, plus comments with their replies. No TikTok account needed.

At a glance

  • Profiles: followers, following, total likes, video count, bio and bio link, verified, business account and category, TikTok Shop seller, live right now, account creation date.
  • Videos: views, likes, comments, shares, saves, reposts, caption, hashtags, mentions, post time, location, language, duration, cover, music (title, artist, original sound), AI-generated label, pinned flag, author with follower count.
  • Comments: text, likes, reply count, post time, language, pinned or liked by the creator, commenter, and replies under each comment.
  • From profiles: each profile's latest videos (up to 10) and pinned videos, with a date filter.
  • Monitoring: turn on Only new videos and comments and schedule the run to get each new video or comment once. Profiles come back every run, so follower growth can be tracked.
  • Price: $1 per 1,000 profiles, $1 per 1,000 videos, $0.30 per 1,000 comments, plus a small start fee per run.

Who uses it

  • Marketers and agencies vetting creators: reach, engagement rate, posting rhythm, shop seller flag.
  • Brands tracking their own and competitors' accounts and the comments under their videos.
  • Researchers and analysts collecting comments for sentiment and topic analysis.

Questions

Questions about TikTok Scraper

How many videos per profile?

The latest 10 plus pinned ones, the same list TikTok shows to visitors who are not logged in. For a longer history, schedule the run with Only new videos and comments and it builds up over time.

Can I search by hashtag or keyword?

Not in this version; paste profiles or video links.

Private accounts?

The profile row is returned; their videos are not visible and are skipped.

Is this personal data?

Profiles, videos and comments are public posts. Usernames of commenters are personal data in some places; use the data within the law that applies to you.

How much does TikTok Scraper cost?

$1 per 1,000, charged only for profiles returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does TikTok Scraper return?

Every row has the same fields, including text, author.username, createdAt, playCount, diggCount, commentCount, shareCount, collectCount. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
