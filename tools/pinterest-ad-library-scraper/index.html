Guide

How Pinterest Ad Library Scraper works

Inputs, options and tips, from the tool's own documentation.

Get the ads shown on Pinterest in EU countries from the Pinterest Ads Repository, by advertiser name or website: title, description, image or video, landing page, first and last date shown, running or stopped, days running, reach range, and the advertiser's Pinterest profile, followers and verified badge. No Pinterest account needed.

At a glance

  • Find ads by advertiser: the name as Pinterest shows it (Nike, Zalando, Sephora) or a website domain.
  • Ad creative: title, description, image links in full size, video links, carousel cards, landing page and display domain.
  • Timing and reach: first and last date shown, running now or stopped, days running, and the range of people reached in the EU. Long-running ads (the ones that work) stand out.
  • Who is behind the ad: advertiser name, Pinterest profile link and picture, followers, verified badge.
  • Filters: EU country, running now or all, date range, up to a year back.
  • Monitoring: turn on Only new ads and schedule the run to get each new ad once.
  • Price: $0.50 per 1,000 ads, below the usual Store price. A small start fee per run; lower prices on higher Apify plans.

Questions

Questions about Pinterest Ad Library Scraper

Which countries?

The Pinterest Ads Repository covers ads shown in EU countries, one country per run. Any other code reads Germany.

Why did an advertiser find nothing?

The name must be the advertiser's name on Pinterest; upper or lower case does not matter. When it is not, the run tries the repository's own name suggestions. Some brands run no Pinterest ads in a given country.

How far back does it go?

A year. Set Ads to All, or set Shown from. The repository updates its dates about once a week, so an ad last shown in the past two weeks counts as running.

Can I search ad text?

No: the repository finds ads by advertiser only.

Need Google, Meta, LinkedIn or TikTok ads too?

Competitor Ads (tacps126/competitor-ads) reads all five libraries in one run, in the same row shape.

How much does Pinterest Ad Library Scraper cost?

$0.50 per 1,000, charged only for pinterest ads returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Pinterest Ad Library Scraper return?

Every row has the same fields, including advertiserName, format, headline, text, landingUrl, previewImageUrl, firstShown, lastShown. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
