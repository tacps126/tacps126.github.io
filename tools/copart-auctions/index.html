Guide

How Copart Auctions Scraper works

Inputs, options and tips, from the tool's own documentation.

Vehicle lots from Copart US for any search: year, make, model and trim, VIN, damage, title, odometer, estimated retail value, repair cost, current bid, Buy It Now price, auction date, yard and photo. Filter like the site does, sort by the best bid for the value, and get only new arrivals for your buy box.

Built for car dealers and rebuilders, exporters and importers, auction brokers, insurance and pricing analysts, and AI agents.

Why this Actor

  • Every filter you need. Make, model, years, odometer, damage, title, vehicle type, Buy It Now, Run and Drive, pure sale, recovered theft, fleet, EV and hybrid, yard state, auction in the next N days, new in the last N days, repair cost.
  • Deal finding. Minimum value, maximum bid, maximum bid / value; sort by the best bid for the value, highest value, newest year or lowest miles.
  • New-arrival alerts. Turn on Only new and schedule it: each run returns only lots earlier runs did not deliver. Send them to Slack, email, Google Sheets or a webhook.
  • AI deal reads (optional). A deal rating at the current bid, risks to check and a note on a sensible maximum bid; with your buy box, a fit score.
  • Fast. 500 lots in a few seconds.
  • For AI agents. Callable as an MCP tool.

How to use it

Clean or salvage 2018+ Camrys, best bid for the value first:

json
{
  "makes": ["TOYOTA"],
  "models": ["CAMRY"],
  "yearFrom": 2018,
  "titleTypes": ["clean", "salvage"],
  "sortBy": "bidToValue",
  "maxItems": 100
}

Run-and-drive pickups in Texas auctioning this week, as an hourly alert:

json
{
  "vehicleTypes": ["pickup"],
  "features": ["runAndDrive"],
  "states": ["TX"],
  "auctionWithinDays": 7,
  "onlyNew": true
}

Pricing

$15 per 1,000 lots plus a small start fee per run. AI insights, when you turn them on, are $0.01 each. On the Apify free plan a run returns up to 100 lots.

Good to know

  • Bids change until the auction ends; currentBid is the bid when the run read the lot. Run again (or schedule it) for fresh bids.
  • Estimated values and repair costs are Copart's figures. This Actor reads public lot listings only; it does not bid or sign in.
  • Need another field or Copart's other countries? Contact tacps126@gmail.com.
Questions

Questions about Copart Auctions Scraper

How much does Copart Auctions Scraper cost?

$15 per 1,000, charged only for lots returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Copart Auctions Scraper return?

Every row has the same fields, including lotNumber, url, title, image, year, make, model, trim, vin, vehicleType, bodyStyle, color, engine, cylinders, fuel, transmission, drive, keys, odometer, odometerStatus, primaryDamage, secondaryDamage, titleType, titleDocument, titleState, estimatedRetailValue, repairCost, currentBid, buyItNowPrice, bidToValue, repairToValue. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
