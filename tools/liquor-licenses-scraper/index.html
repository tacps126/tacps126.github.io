Guide

How Liquor License Scraper works

Inputs, options and tips, from the tool's own documentation.

New liquor licenses and license applications in one format, read from the official open-data tables of the licensing authorities. Each license comes with the business and legal name, license type, status, address, county and dates: a list of bars, restaurants, stores and venues that just got (or just applied for) the right to sell alcohol.

At a glance

  • Areas: Texas (statewide), New York State (statewide), New York State new applications, and Chicago. Any other city or state that publishes its liquor licenses on an open-data site: paste the table's address.
  • New licenses first: Texas and New York by the date the license was first issued, New York applications by the date they were received, Chicago new liquor licenses (not renewals).
  • Before they open: New York applications are pending licenses, places that are about to open.
  • Filters: issued in the last N days, keywords in the business name or license type (restaurant, bar, brewery, package store...), words to leave out.
  • Monitoring: turn on Only new since last run and put the run on a schedule to get each new license once.
  • Price: $4 per 1,000 licenses, plus a small start fee per run. Empty runs cost only the start fee.

Who uses it

  • Beverage distributors, brand reps and importers looking for new accounts.
  • POS, payroll, insurance, music licensing and security sales teams selling to new bars and restaurants.
  • Restaurant suppliers, equipment and furniture companies, and local agencies.

Questions

Questions about Liquor License Scraper

How fresh is the data?

As fresh as each authority's table, usually updated daily.

Is this personal data?

Liquor licenses are public records about businesses. Some name an individual licensee; use them within the law that applies to you, including rules on unsolicited calls and email.

How much does Liquor License Scraper cost?

$4 per 1,000, charged only for licenses returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Liquor License Scraper return?

Every row has the same fields, including jurisdiction, issuedDate, businessName, legalName, licenseType, status, address, locality. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
