Guide

How China Wholesale Scraper works

Inputs, options and tips, from the tool's own documentation.

Search Alibaba.com and AliExpress by keyword and read Alibaba and 1688 product pages, all in one record shape: price range and price per quantity break, MOQ, unit, sold count, rating, supplier name, country, years on the platform, business type, on-time delivery and response time, attributes, variants and images. Compare suppliers across three marketplaces without writing three data handlers, and schedule it to catch new listings in your niche.

Built for e-commerce sellers and dropshippers sourcing products, procurement and sourcing teams, market researchers comparing suppliers and prices, and AI agents.

How to use it

Compare suppliers for a product on Alibaba and AliExpress:

json
{
  "searchTerms": ["led strip light", "solar panel 400w"],
  "maxItemsPerSearch": 60
}

Full details for every Alibaba result (price breaks, specs, supplier type, delivery rate):

json
{
  "searchTerms": ["silicone phone case"],
  "sites": ["alibaba"],
  "includeDetails": true,
  "maxItemsPerSearch": 30
}

1688 and Alibaba products by link or 1688 offer ID:

json
{
  "productUrls": [
    "https://detail.1688.com/offer/735353578254.html",
    "735353578254",
    "https://www.alibaba.com/product-detail/IP20-IP65-IP67-IP68-Waterproof-Rgb_1600522546292.html"
  ]
}

Watch a niche for new listings: add Only new results, give the monitor a name and schedule the Actor daily or weekly. Each run returns only products earlier runs did not deliver. Send them to Slack, Discord, a webhook or Google Sheets with Delivery.

Pricing

  • $2.50 per 1,000 search results (Alibaba and AliExpress results pages).
  • $4.00 per 1,000 full products (1688 and Alibaba product pages, or Alibaba results with Full details on).
  • Plus a small start fee per run. On the Apify free plan a run returns up to 100 products.

Good to know

  • 1688 titles and specs are in Chinese, as 1688 lists them; prices are in yuan.
  • A marketplace sometimes shows a check page instead of data. The Actor then retries on another connection; if a page still refuses, it is listed in the run's warnings and the rest of the run goes on.
  • Prices and stock change often. Schedule runs for fresh numbers instead of reusing old ones.
  • Only public product information is read; no login or account is used.

Questions

Questions about China Wholesale Scraper

How much does China Wholesale Scraper cost?

$2.50 per 1,000, charged only for search results returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does China Wholesale Scraper return?

Every row has the same fields, including site, productId, url, title, priceMin, priceMax, originalPrice, currency, priceTiers, moq, unit, soldCount, rating, reviewCount, supplierName, supplierId, supplierUrl, supplierCountry, supplierYears, supplierType, supplierOnTimeDelivery, supplierResponseTime, certifications, attributes, variants, images. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
