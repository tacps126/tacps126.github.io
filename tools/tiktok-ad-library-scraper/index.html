Guide

How TikTok Ad Library Scraper works

Inputs, options and tips, from the tool's own documentation.

Get the ads shown on TikTok in Europe, the UK, Switzerland, Turkey and Brazil from the TikTok Ad Library, by advertiser or keyword: advertiser, caption, video and cover image, first and last date shown, running or stopped, days running, reach range and topic. No TikTok account needed.

At a glance

  • Find ads your way: advertiser name as TikTok shows it, website domain, a link copied from the Ad Library, or keywords.
  • Ad creative: caption, video link and cover image.
  • Timing and reach: first and last date shown, running now or stopped, days running, and the range of people reached. Long-running ads (the ones that work) stand out.
  • Filters: country, running now or all, date range, ad type (video, image).
  • Monitoring: turn on Only new ads and schedule the run to get each new ad once.
  • Price: $0.40 per 1,000 ads, below the usual Store price. A small start fee per run; lower prices on higher Apify plans.

Questions

Questions about TikTok Ad Library Scraper

Which countries?

The TikTok Ad Library covers ads shown in the EU and EEA, Switzerland, the UK, Turkey and Brazil. Pick one of them, or ALL for all.

Do the video links last?

TikTok's media links expire after some days. Download the files you want to keep soon after the run.

Need Google, Meta or LinkedIn ads too?

Competitor Ads (tacps126/competitor-ads) reads all four libraries in one run, in the same row shape.

How much does TikTok Ad Library Scraper cost?

$0.40 per 1,000, charged only for tiktok ads returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does TikTok Ad Library Scraper return?

Every row has the same fields, including source, advertiserName, creator, format, headline, text, callToAction, landingUrl. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
