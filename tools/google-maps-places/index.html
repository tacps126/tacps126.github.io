Guide

How Google Maps Scraper works

Inputs, options and tips, from the tool's own documentation.

Turn any Google Maps search into a lead list: business name, categories, full address split into street, city, postal code and state, phone number, website, rating and review count, opening hours, open or closed status, GPS coordinates, place ID and a map link. Search for dentist in Denver, CO, combine many terms with many cities, or paste Google Maps search links. Export to JSON, CSV or Excel, send to Google Sheets or your CRM, or call it as an API.

Built for sales teams and agencies building local lead lists, marketers mapping competitors, franchise and real-estate analysts sizing markets, and data teams who need clean place data.

Why this scraper

  • Terms x locations. Give dentist, orthodontist and five cities; every term runs in every city.
  • Contact-ready rows. Phone in local and international format, website and its domain, street address with postal code.
  • Filters that save money. Only places with a website, only places with a phone, minimum rating, skip closed places. Filtered places are not charged.
  • Hours and status. Weekly opening hours plus "Open, closes 5 PM" or closed flags.
  • Reviews and details. Turn on Add reviews and details for the star rating breakdown, the top reviews on each place (author, rating, text, when) and its About attributes (accessibility, payments, amenities), at the same price per place.
  • No duplicates. A place found by two searches is delivered and charged once.
  • New-business alerts. Schedule it with Only new places and each run returns only places you haven't received yet.

How to use it

  1. Add Search terms (for example dentist) and Locations (for example Denver, CO), or paste Google Maps search links.
  2. Optionally set filters and Max places per search.
  3. Press Start. Download from the Output tab, or connect an integration.

Example input

json
{
  "searchTerms": ["dentist", "orthodontist"],
  "locations": ["Denver, CO", "Boulder, CO"],
  "maxPlacesPerSearch": 100,
  "onlyWithWebsite": true,
  "minRating": "4"
}

Pricing

Pay per result: about $2 per 1,000 places (lower on higher Apify plans) plus a small start fee. Duplicates, filtered places and (with Only new places) already-delivered places are free. See the Pricing tab for exact rates, and set a maximum charge per run to cap spend.

On Apify's free plan each run returns up to 100 places, enough to try it out. Any paid Apify plan removes the limit.

Questions

Questions about Google Maps Scraper

How many places per search?

Google Maps lists up to about 180 places for one search. For more, split a city into neighborhoods or ZIP codes, or use more specific terms.

Do you get emails?

Not from Google Maps, which does not show them. Feed the website column to a contact finder to get emails and social links.

Can I get reviews?

Turn on Add reviews and details for the top reviews Google shows on each place (about 5) and the full star breakdown. It returns those top reviews, not every review of a place.

Is it legal?

The Actor collects publicly listed business information. You're responsible for how you use the data under the laws that apply to you.

How much does Google Maps Scraper cost?

$2 per 1,000, charged only for places returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Google Maps Scraper return?

Every row has the same fields, including name, category, categories, address, street, neighborhood, city, postalCode, state, countryCode, phone, phoneInternational, website, domain, rating, reviewsCount, reviewsUrl, openingHours, openStatus, closed, latitude, longitude, timezone, placeId, cid, url. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
