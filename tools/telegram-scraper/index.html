Guide

How Telegram Channel Scraper works

Inputs, options and tips, from the tool's own documentation.

Posts from public Telegram channels with text, date, views, reactions, photos, video thumbnails, links, hashtags, mentions, forwards and link previews. Add channel info (title, description, subscribers, photos, videos, links, verified), search inside channels for words, or give a topic and get the public channels about it. No login, no phone number.

Built for crypto and market researchers, social listening and brand monitoring teams, journalists and OSINT analysts, marketers, and AI agents.

Why this Actor

  • Three ways in: a list of channels, words searched inside those channels, or a topic that finds the channels for you.
  • Views and reactions on every post, parsed to plain numbers (5.89M becomes 5890000).
  • Filters: last N days or a date range, minimum views, minimum subscribers, words to leave out.
  • Monitoring built in: turn on Only new posts and schedule it; each run returns only posts it has not delivered before.
  • For AI agents. Callable as an MCP tool.

How to use it

The last week of posts from two channels:

json
{ "channels": ["durov", "telegram"], "postedWithinDays": 7 }

Posts mentioning a word in a set of channels:

json
{ "channels": ["cointelegraph", "wublockchainenglish"], "searchTerms": ["ETF"], "maxPostsPerChannel": 100 }

Find channels about a topic, with their latest posts:

json
{ "searchTerms": ["web scraping"], "maxChannelsPerSearch": 30, "maxPostsPerChannel": 10, "minSubscribers": 500 }

Pricing

$0.60 per 1,000 results (posts and channel rows alike), plus a small start fee per run. On the Apify free plan a run returns up to 100 results.

Good to know

  • Topic search finds channels by their name and description; well-known topics work best, and a few listed channels may no longer exist (those are skipped).
  • Only public channels with a public post preview can be read. Groups, people and bots return their info row only; private invite links can't be read.
  • Comments under posts are not included.

Questions

Questions about Telegram Channel Scraper

How much does Telegram Channel Scraper cost?

$0.60 per 1,000, charged only for results returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Telegram Channel Scraper return?

Every row has the same fields, including channel, postId, url, date, text, views, reactions, reactionsTotal, photos, hasVideo, videoThumbnail, documents, poll, linkPreview, links, hashtags, mentions, isForwarded, forwardedFrom, forwardedFromUrl, replyToUrl, isEdited, author, Channel rows: username, title, description, kind, subscribers, members, photos, videos, links, verified, avatar, type, source, scrapedAt. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
