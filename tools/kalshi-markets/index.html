Guide

How Kalshi Scraper works

Inputs, options and tips, from the tool's own documentation.

Every Kalshi market you need in one table: probability, yes and no bid and ask, 24-hour change, volume, open interest, liquidity, close date, rules and, once settled, the result. Search by keyword or category, paste tickers or links, add daily price history, and schedule it to get an alert row whenever a market moves by the points you choose.

Built for traders and forecasters, journalists and newsletters, quant and research teams, app and bot builders, and AI agents.

How to use it

Trending Kalshi markets right now:

json
{ "maxItems": 50 }

Every Fed-decision market with 30 days of history:

json
{ "search": "fed", "historyDays": 30 }

Economics and finance markets closing in the next 7 days:

json
{ "categories": ["economics", "finance"], "closesWithinDays": 7, "sortBy": "closingSoon" }

Alert when an election market moves 5 points (schedule hourly):

json
{ "categories": ["elections"], "minVolume24h": 1000, "alertMovePoints": 5 }

A whole series, event or single market by ticker:

json
{ "markets": ["KXFEDDECISION", "KXFEDDECISION-26DEC", "KXFEDDECISION-26DEC-H0"] }

Questions

Questions about Kalshi Scraper

How much does Kalshi Scraper cost?

$3 per 1,000, charged only for markets returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Kalshi Scraper return?

Every row has the same fields, including marketId (ticker), eventId, seriesTicker, eventTitle, question, outcome, url, probability, lastPrice, yesBid, yesAsk, noBid, noAsk, spread, change24h, volume, volume24h, openInterest, liquidity, category, openTime, closeTime, status (open, closed, resolved), result (Yes, No), rules. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
