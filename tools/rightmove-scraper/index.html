Guide

How Rightmove Scraper works

Inputs, options and tips, from the tool's own documentation.

Get property listings from Rightmove, the UK's largest property portal, as a clean, spreadsheet-ready dataset: homes to rent or buy anywhere in England, Scotland and Wales. Each listing includes the price (with per-month or per-week rent), bedrooms and bathrooms, address and postcode district, GPS coordinates, key features, the estate agent with their branch phone number, photos, the date it was added and a price-reduced flag. Export to JSON, CSV or Excel, send to Google Sheets, or call it as an API.

Built for buy-to-let investors and analysts tracking prices and yields, estate and letting agents watching competitors, relocation and proptech teams, and anyone who wants new or reduced listings the moment they appear.

Why this scraper

  • Fast and cheap. Results are read straight from Rightmove's pages without a browser, so a run is quick and costs very little to run.
  • Plain-word locations. Type Manchester, Camden, Bristol or a postcode district like SW18. The Actor finds the matching Rightmove area. Or paste any Rightmove search URL with your filters.
  • Price-cut tracking. Every listing says whether it was just reduced (priceReduced) and shows Rightmove's "Added on.../Reduced on..." text, so you can spot motivated sellers and landlords.
  • Agent contact included. Agent brand, branch name and branch phone number come with every listing.
  • Filters. Rent or buy, flats or houses, price range, bedrooms, newest first.
  • New-listing alerts. Schedule it with Only new listings and each run returns only listings you haven't received yet, so you pay only for new ones.
  • Price-change tracking. Turn on Changes only and schedule it: each run returns only listings that are new, whose price, rent, size, rooms or title changed (with the old and new values, e.g. "changes": {"price.amount": {"old": 1450, "new": 1395}}), or that were taken down (changeType: "removed"). Unchanged listings are skipped and not charged. Each changed listing also carries priceHistory (dated prices across runs).
  • Price-cut feed. Turn on Price drops only and schedule it daily: you get only listings whose price went down, with old and new price and the history.

How to use it

  1. Add Locations (e.g. Manchester, Camden) and choose Rent or buy and Property type (flat or house).
  2. Optionally set price and bedrooms filters and Sort by: Newest listed.
  3. Press Start. Download results from the Output tab, or connect an integration.

Questions

Questions about Rightmove Scraper

How many listings can I get per search?

Rightmove shows up to 42 pages (about 1,000 listings) per search. For more, split by area (boroughs, postcode districts) or price bands.

Does it include the agent's phone number?

Yes, the branch phone Rightmove shows on each listing. Use it within UK GDPR and PECR rules.

Is it legal?

The Actor collects publicly listed property ads. You're responsible for how you use the data under the laws that apply to you.

How much does Rightmove Scraper cost?

$1 per 1,000, charged only for listings returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Rightmove Scraper return?

Every row has the same fields, including title, url, id, offerType, propertyType, listingKind, price, priceText, bedrooms, bathrooms, sizeText, address, latitude, longitude, keyFeatures, summary, agentCompany, agentName, agentPhone, agentLogo. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
