Guide

How Google Trends Scraper works

Inputs, options and tips, from the tool's own documentation.

Scrape Google Trends for any term or comparison of up to 5 terms: interest over time, interest by region (countries, states, US metro areas or cities), top and rising related queries and related topics, for any country or region, time range, category and search type (web, images, news, Google Shopping, YouTube). Also reads Trending Now for any country: what people search for right now, with search volume, growth, start and end time, categories and related searches.

Built for SEO and keyword research, content planning, product and market research, brand and competitor tracking, newsrooms, and datasets for AI and analytics.

At a glance

  • Price: $2.50 per 1,000 searches (each search is one row with every part) and $1 per 1,000 Trending Now trends. Free plan: up to 100 results per run.
  • One row per search: the chart, the regions, the related queries and topics come together, so a comparison of 5 terms is one result, not dozens.
  • Trend alerts: schedule it with Only new trends and get each new trending search once, in Slack, Discord, a webhook or Google Sheets.
  • First run: the prefilled input returns 2 searches and 25 US trends in a few seconds.

How to use it

json
{
  "searchTerms": ["chatgpt", "n8n, zapier, make.com"],
  "geo": "US",
  "timeRange": "today 3-m",
  "regionResolution": "DMA",
  "trendingGeos": ["US", "GB", "IN"],
  "trendingHours": "24",
  "trendingCategories": ["18"],
  "onlyNew": true
}
  • Search terms. One search per line. Separate up to 5 terms with commas to compare them on one chart, or tick Compare all terms on one chart.
  • Google Trends URLs. Paste Explore or Trending Now page links; their terms, place, time range, category and search type are used as they are.
  • Place, time and type. Worldwide or any country or region code (US, GB, US-CA); past hour to 2004 to present, or your own dates (2024-01-01 2024-06-30); any Trends category; web, image, news, Shopping or YouTube search.
  • Region detail. Countries, subregions (states), US metro areas or cities, with or without low-volume places.
  • Pick the parts. Interest over time, by region, related queries and related topics are all on by default; turn off what you don't need for faster runs.
  • Trending Now. Add country or region codes; pick the window (4 hours to 7 days), categories, active trends only or a minimum search volume.
  • Follow new trends. Turn on Only new trends and schedule the Actor: each run returns only trends earlier runs haven't delivered.

Pricing

$2.50 per 1,000 searches and $1 per 1,000 Trending Now trends, plus a small start fee per run. A search is charged once, whatever it includes (up to 5 terms, the chart, the regions, the related queries and topics). Searches that fail are not charged; with Only new trends, trends you already received are not charged.

Free-plan runs return up to 100 results per run.

Good to know

  • Google Trends shows relative interest (0 to 100), not search counts. Compare terms in one search to put them on the same scale. Trending Now shows Google's rounded search volumes (200K+).

Questions

Questions about Google Trends Scraper

Does it need a Google account or an API key?

No.

Why is a part of a search missing?

Google had too little data for it (for example a rare term in a small region), or it could not be read this time. The row lists it under missingParts and the run summary says why.

Why do the numbers differ slightly from what I saw in the browser?

Google Trends samples its data, so values can move by a few points between requests, and the last point of a period is still filling up (isPartial).

Can I get daily data for a long period?

Google picks the detail from the period: up to about 9 months gives daily points, longer gives weekly or monthly ones.

How much does Google Trends Scraper cost?

$2.50 per 1,000, charged only for search results returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Google Trends Scraper return?

Every row has the same fields, including searchTerm, searchTerms, geo, timeRange, startDate, endDate, resolution, category, searchType, interestOverTime, averages, interestByRegion, regionResolution, relatedQueriesTop, relatedQueriesRising. Download as JSON, CSV, Excel or XML.
