Guide

How RAG Web Search works

Inputs, options and tips, from the tool's own documentation.

Search the web and get the top result pages as clean Markdown, ready for AI agents, RAG and LLM apps. Each row has the search rank, title and snippet, plus the page's main content as Markdown without menus, footers or ads, and its title, description, language and publish date.

Built for AI agents that need fresh web context, chatbots that answer from current pages, researchers collecting sources, and RAG pipelines.

Why this search

  • Pages, not just links. Each result is opened and its main content returned as Markdown.
  • Clean text. Navigation, sidebars, footers and ads are dropped; headings, lists, tables and code are kept.
  • Many searches at once. List questions or phrases; each gets its own top results.
  • Your region. Set the search language and country.
  • Fast. Result pages are read at the same time; five pages in a few seconds.

How to use it

  1. Add Web searches (questions or phrases).
  2. Set Results per search (3 to 5 is usual for an agent).
  3. Press Start, or call it as an API from your agent.
json
{
  "queries": ["how does retrieval augmented generation work", "best vector database 2026"],
  "maxResultsPerQuery": 5
}

Pricing

Pay per page: $1 per 1,000 pages, plus a small start fee per run. You pay only for pages delivered.

Questions

Questions about RAG Web Search

Which search engine?

A major web search engine's public results page, in the language and country you set.

What about pages that need JavaScript?

Those come back thin; set a minimum word count to skip them.

Can I crawl a whole site?

Use Website to Markdown Crawler.

How much does RAG Web Search cost?

$1 per 1,000, charged only for pages returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does RAG Web Search return?

Every row has the same fields, including query, rank, url, title, wordCount, searchSnippet, markdown. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_web_for_rag.
