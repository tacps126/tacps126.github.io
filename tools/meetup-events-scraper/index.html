Guide

How Meetup Events Scraper works

Inputs, options and tips, from the tool's own documentation.

Get Meetup events as a clean, spreadsheet-ready list: name, start and end time, online or in person, venue with address, the organising group with its Meetup page, status, and the full description. Search by keyword and city, or paste any Meetup search or group link.

Built for: developer-relations and community teams finding groups to sponsor or speak at, event marketers, recruiters looking for tech communities, and founders mapping a city's scene.

Why this scraper

  • Groups behind the events. Every event comes with the group that runs it and the group's page, a ready list of communities.
  • Search like a person. AI in London, python in Bengaluru, startup online. About 70 big cities are known by name; for any other write City, CC (e.g. Lyon, FR).
  • Or paste links: a Meetup search or a group's events page.
  • Fast and light. No login needed; a run takes seconds.
  • New-event alerts. Schedule it with Only new events and each run returns only events you haven't received yet.
  • Change alerts. Turn on Changes only and schedule it: each run returns only new events, events whose date, venue, status, price or sold-out state changed (old and new values in changes), and upcoming events that disappeared (changeType: "removed", cancelled or unlisted).

How to use it

  1. Type Topics or keywords (e.g. AI) and a Location (e.g. London, or online), or paste Event links.
  2. Press Start. Download from the Output tab, or connect Google Sheets, Slack, Make, Zapier, n8n or webhooks.

A Meetup search returns its first page of results, about 30 events per keyword and city. Add related keywords for more.

Pricing

Pay per result: about $1 per 1,000 events. Past events and (with Only new events) events you already received are free. On Apify's free plan a run returns up to 200 events, enough to try it.

Use it in n8n, Make, Zapier or AI agents

Every run is one API call (run-sync-get-dataset-items). In n8n, use an HTTP Request node or Apify's own node. AI agents can call it through Apify's hosted MCP server.

More event sites in one run

This Actor reads Meetup only. Events Scraper searches Luma, Eventbrite and Meetup together and returns them in this same format. For trade-show exhibitor lists, see Trade Show Exhibitor List Scraper.

Notes

  • Only public event pages are read. Organiser and host names are shown as published; use personal data within GDPR and the site's terms.
  • Pages that ask for a human check (captcha) are skipped and reported in the run log; this Actor does not solve captchas.
Questions

Questions about Meetup Events Scraper

How much does Meetup Events Scraper cost?

$1 per 1,000, charged only for events returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Meetup Events Scraper return?

Every row has the same fields, including name, url, source, startAt, endAt, timezone, isOnline, status, venue, organizer, price, description, imageUrl, foundVia. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
