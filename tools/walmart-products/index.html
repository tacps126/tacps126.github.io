Guide

How Walmart Scraper works

Inputs, options and tips, from the tool's own documentation.

Products from Walmart.com for any search, category or product link: price and was-price, rating and review count, seller, stock, delivery and pickup, sponsored flag and badges. Turn on Product details for brand, model, UPC, full specifications, description, seller rating, return policy, rating breakdown, review highlights and top reviews. Schedule it with Only new or changed to get price and stock alerts with a price history.

Built for e-commerce sellers and brands, pricing and assortment analysts, resellers and dropshippers, market researchers and AI agents.

Why this Actor

  • Search, category and product links in one run, up to 25 result pages per search.
  • Filters: price range, minimum rating, in stock only, leave out sponsored placements; sort by price, best sellers, rating or newest.
  • Price and stock monitoring with change details and history.
  • Fast and low cost: a few seconds per results page.
  • For AI agents. Callable as an MCP tool.

How to use it

json
{ "searchQueries": ["air fryer"], "maxItemsPerSearch": 200, "sortBy": "best_seller", "minRating": 4 }

Daily price and stock alerts for a category:

json
{ "startUrls": ["https://www.walmart.com/browse/electronics/laptops/3944_3951"], "onlyChanges": true, "monitorName": "laptops" }

Pricing

$3 per 1,000 products plus a small start fee per run; product details add $2.20 per 1,000 product pages, so a product with full details is $5.20 per 1,000. Higher Apify plans pay less (up to 15% off). On the Apify free plan a run returns up to 100 products.

Good to know

  • Public product pages only, as shown to a US visitor; nothing behind a sign-in.
  • Prices and stock change often; scrapedAt says when each row was read.

Questions

Questions about Walmart Scraper

How much does Walmart Scraper cost?

$3 per 1,000, charged only for products returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Walmart Scraper return?

Every row has the same fields, including itemId, name, brand, url, image, price, wasPrice, unitPrice, savings, rating, reviewsCount, seller, sellerId, availability, inStock, fulfillment, sponsored, badges, category, position, page. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_walmart_products.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
