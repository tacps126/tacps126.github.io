YouTube comments and replies for any video, Short, playlist, channel or search: text, author, likes, replies, pinned and creator-hearted flags, dates. Top or newest, filters, only-new alerts and an AI summary of what viewers say.

Only comments containing one of these words, e.g. your brand or product.

Leave out comments containing any of these.

Monitoring

Schedule the Actor (with Newest first) and each run returns only comments earlier runs did not deliver: alerts for your videos, brand or competitors.

AI insights (optional)

Add one summary row per video: overall sentiment, themes, questions, complaints, praise and follow-up video ideas from the comments read.

Who you are, e.g. "Skincare brand watching review videos of our serum". Adds a fit score.

Python · pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("tacps126/youtube-comments").call(run_input={
    "videos": ["https://www.youtube.com/watch?v=dQw4w9WgXcQ"],
    "maxCommentsPerVideo": 100,
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
JavaScript · npm i apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });
const run = await client.actor('tacps126/youtube-comments').call({
  "videos": [
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
  ],
  "maxCommentsPerVideo": 100
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
