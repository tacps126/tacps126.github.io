Guide

How Map Your Show Exhibitor List Scraper works

Inputs, options and tips, from the tool's own documentation.

Get the exhibitor list of any Map Your Show trade show as a clean, spreadsheet-ready lead list: company name, booth and hall, email, phone, website, full address, social profiles, product categories, description and logo. Covers SEMA Show, NAB Show, IMTS, AHR Expo, IPPE, HIMSS, InfoComm, GSX and hundreds more US shows. Paste the exhibitor-list link of any <show>.mapyourshow.com exhibitor gallery and get that exact show and year.

Built for sales and business-development teams prospecting before and after a show, exhibitors researching who else is exhibiting, event marketers and agencies, and market researchers mapping an industry.

At a glance

  • Price: $1 per 1,000 exhibitors. Free plan: up to 200 exhibitors per show in every run.
  • First run: the prefilled input returns 50 exhibitors of SEMA Show 2026 (Las Vegas, USA) - Automotive Aftermarket in seconds.
  • Other platforms: shows on Messe Frankfurt, Messe Düsseldorf, RX, Map Your Show, a2z, Koelnmesse, NürnbergMesse, Swapcard, ExpoPlatform and more in one run: Exhibition Scraper (90+ built-in shows).

Why this scraper

  • Contacts, not just names. With Include contact details on (default), each exhibitor's profile is opened for email, phone, website, address and social links, where the organiser publishes them.
  • Any Map Your Show show by link. The Actor reads the event from the page you give it, so a site that hosts several shows, cities or years never mixes them up.
  • One format for every show. Booth, contact, address and socials always land in the same fields, so several shows combine into one table.
  • Watch a list fill up. Exhibitor lists grow for months before a show. Turn on Only new exhibitors and schedule the Actor: each run returns only companies added since the last run.

Any Map Your Show show by URL

Paste a link in Exhibitor list URLs: any <show>.mapyourshow.com exhibitor gallery. The run log says what each link was matched to, and every record carries the link in exhibitionUrl. Turn on Only check the links (free) to see whether a link is supported without scraping anything.

json
{
  "startUrls": [{ "url": "https://nab26.mapyourshow.com/8_0/explore/exhibitor-gallery.cfm" }],
  "maxResults": 500
}

A link from another platform is skipped with a note (and not charged); Exhibition Scraper reads it.

How to use it

  1. Pick one or more shows in Exhibitions, or paste links in Exhibitor list URLs (both work together).
  2. Optionally set Max exhibitors (try 20 first) and turn Include contact details off for a quick names-and-booths list.
  3. Press Start. Download results from the Output tab, or connect an integration (Google Sheets, HubSpot, Slack, webhooks).

Contact details

Map Your Show lists only names and booths on its exhibitor pages; profile details sit one level deeper. With Include contact details on (the default), the Actor collects them inside your run:

  1. Exhibitors are written straight into your run's dataset, so you still get one dataset.
  2. You're billed once per exhibitor at the normal price, plus a small start fee for a second map-your-show-exhibitor-scraper run you may see in your Runs list. It stops when your run stops.

Turn Include contact details off for a faster names-and-booths-only list.

Emails for every exhibitor

Many organisers list a company's website but not its email (Koelnmesse keeps it behind a login; Map Your Show, Newfront and NürnbergMesse often leave it out). Turn on Find emails on company websites and, for each exhibitor with a website but no email, the Actor reads the company's own site (home, contact and imprint pages) and adds the email, phone and social profiles it finds, marked contactSource: "company website". In a BIOFACH test, 11 of 20 exhibitors without an email got one. No extra charge; runs take longer.

Track changes before a show

Turn on Changes only and schedule the Actor (for example weekly in the months before a show). Each run returns only:

  • new exhibitors (changeType: "new"),
  • exhibitors whose booth, email, phone, website or address changed, with the old and new values: "changes": {"booth": {"old": "B12", "new": "C40"}},
  • exhibitors who dropped out of the list (changeType: "removed"; only when the whole list was read, so leave Max results empty).

Unchanged exhibitors are skipped and not charged. The first run returns everyone as new and becomes the baseline.

Questions

Questions about Map Your Show Exhibitor List Scraper

How much does Map Your Show Exhibitor List Scraper cost?

$1 per 1,000, charged only for exhibitors returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Map Your Show Exhibitor List Scraper return?

Every row has the same fields, including name, exhibition, exhibitionUrl, booth, contact, address, social, categories. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
