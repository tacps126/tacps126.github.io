Guide

How Gov Radar works

Inputs, options and tips, from the tool's own documentation.

Official government updates from several countries in one clean, filtered feed: new rules and proposed rules, notices, guidance, consultations, press releases and regulator circulars, straight from the government's own sources. Pick sectors and keywords, schedule it, and get only what's new, as a dataset, an RSS feed, a Slack message or rows in Google Sheets.

Built for compliance and regulatory-affairs teams, banks, fintechs and asset managers, policy and public-affairs consultants, law firms, trade associations, journalists, and AI agents that need to know what governments published today.

Why this Actor

  • One schema for every government. jurisdiction, authority, type, title, summary, url, publishedAt, plus commentsCloseOn, effectiveDate, documentNumber and pdfUrl where the source has them.
  • Sector filters. Banking & payments, securities, insurance, tax & customs, trade & sanctions, health & pharma, food & agriculture, energy, environment & climate, technology/AI/data, transport, employment, housing, procurement, defence, education. Every update is tagged with its sectors.
  • Keyword, authority and type filters. Whole-word matching on title and summary (so "AI" doesn't match "said"), any agency or department by name, and update types such as rule, proposed-rule, consultation or circular.
  • Regulatory alerts. Turn on Only new updates and schedule it daily or hourly: each run returns only what earlier runs didn't deliver, so you pay only for new items.
  • RSS feed, Slack, Sheets, webhooks. Follow the Standby URL with &format=atom in any feed reader, or send each run's results to Slack, Discord, Google Sheets or a webhook.
  • For AI agents. Callable as an MCP tool from Claude, Cursor and other clients.

How to use it

  1. Pick sectors and/or type keywords (e.g. AI, stablecoin, battery, sanctions).
  2. Choose countries / regions (or specific sources), and add any RSS feeds or official list pages you follow.
  3. Press Start. For alerts, turn on Only new updates and add a daily schedule.
json
{
  "sectors": ["banking", "securities"],

  "postedWithinDays": 7,
  "onlyNew": true

Good to know

Updates are copied as published; the official source is always linked. Crown copyright material (GOV.UK) is used under the Open Government Licence; US federal documents are public domain; EU and Indian sources are reused under their sites' terms. This is not legal advice.

Questions

Questions about Gov Radar

How much does Gov Radar cost?

$3 per 1,000, charged only for updates returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Gov Radar return?

Every row has the same fields, including publishedAt, jurisdiction, authority, type, title, summary, url, sectors, commentsCloseOn, effectiveDate, documentNumber, pdfUrl, topics, documents, pageUrl. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_gov_updates.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
