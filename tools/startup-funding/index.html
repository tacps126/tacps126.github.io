Guide

How Startup Funding Rounds works

Inputs, options and tips, from the tool's own documentation.

Freshly funded companies from SEC Form D filings, the notice US companies file when they raise private money (seed, venture, private equity rounds). For each raise: company, address and phone, industry, amount raised and offered, number of investors, type of securities (equity, SAFEs, debt...), first sale date, and the founders, executives and directors behind it with their roles. Filter by state, industry and size; get only new filings every day.

Built for B2B sales teams selling to newly funded startups, VCs and angels tracking deal flow, recruiters, lenders, accountants and service providers, journalists, and AI agents.

Why this Actor

  • Official source, every filing. About 300-500 Form D filings arrive every weekday.
  • Operating companies by default. Investment funds and amendments are left out unless you want them.
  • Filters: state, industry, words in the filing, minimum amount raised, minimum round size, young companies only.
  • Daily lead feed. Turn on Only new filings, schedule it, and send new raises to your CRM, Slack, Google Sheets or a webhook.
  • For AI agents. Callable as an MCP tool.

How to use it

Tech companies in California that raised at least $1M this week:

json
{ "postedWithinDays": 7, "states": ["CA"], "industries": ["Other Technology"], "minAmountRaised": 1000000 }

A daily feed of new biotech raises across the US:

json
{ "postedWithinDays": 2, "industries": ["Biotechnology", "Pharmaceuticals"], "onlyNew": true }

Pricing

$5 per 1,000 filings plus a small start fee per run. On the Apify free plan a run returns up to 100 filings.

Good to know

  • Form D is a notice: amounts are what the company reported, and some companies file after the round closes.
  • Phone numbers and people are as filed with the SEC (public record).

Questions

Questions about Startup Funding Rounds

How much does Startup Funding Rounds cost?

$5 per 1,000, charged only for filings returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Startup Funding Rounds return?

Every row has the same fields, including company, cik, entityType, yearIncorporated, jurisdiction, street, city, state, zip, phone, industry, revenueRange, totalAmountSold, totalOfferingAmount, totalRemaining, investors, hasNonAccreditedInvestors, minimumInvestment, securities, exemptions, firstSaleDate, people, filed, form, isAmendment, filingUrl, documentUrl. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_startup_funding.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
