Guide

How US Import Records works

Inputs, options and tips, from the tool's own documentation.

US customs import records (sea bills of lading) for any US importer or overseas supplier: total and last-12-month shipments with the trend, who they buy from (or, for a supplier, its US customers), products by HS code, source countries, ports and carriers, the most recent bills of lading, and lookalike importers: other US companies buying from the same factories.

Built for sourcing and procurement teams finding factories, freight forwarders and customs brokers prospecting importers, B2B sales teams qualifying accounts, competitive and supply-chain analysts, and AI agents.

Why this Actor

  • Trend, not just totals: last 12 months against the 12 before, so you see who is growing, shrinking or stopped.
  • Lookalike importers: the US companies that use the same factories as your customer or competitor, ranked by shared suppliers. A ready prospect list.
  • Both directions: start from an importer to see its suppliers, or from a factory to see its US buyers.
  • Shipment alerts: schedule with Recent shipments and Only new shipments to get a competitor's or supplier's new bills of lading.
  • Names or links: type a company name, or paste its importyeti.com page link when the name is ambiguous.
  • For AI agents. Callable as an MCP tool.

How to use it

Who supplies Allbirds, and which other brands use the same factories:

json
{ "companies": ["Allbirds"], "findLookalikes": true }

New shipments of two competitors, every week:

json
{ "companies": ["Allbirds", "https://www.importyeti.com/company/on"], "includePartners": false, "includeShipments": true, "onlyNew": true }

US customers of a factory:

json
{ "suppliers": ["https://www.importyeti.com/supplier/regina-miracle-international"] }

Pricing

$4 per 1,000 profiles, $1 per 1,000 supplier or customer rows, $1.50 per 1,000 shipments and $2 per 1,000 lookalikes, plus a small start fee per run. On the Apify free plan a run returns up to 50 rows.

Good to know

  • Records are public US customs sea-import manifests (bills of lading) as published on ImportYeti; air and land imports are not in them. Companies can ask US Customs to keep their manifests confidential; confidentialSince shows when that started, and newer shipments are then missing.
  • A name finds the page with the same name; if a company trades under another name, paste its page link.

Questions

Questions about US Import Records

How much does US Import Records cost?

$4 per 1,000, charged only for company or supplier profiles returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does US Import Records return?

Every row has the same fields, including profile (role: importer or supplier), supplier / customer row, shipment row, lookalike row. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_import_records.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
