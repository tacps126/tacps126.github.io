Scrape any show by URL

Paste a link in Exhibitor list URLs instead of picking a show. It can be the exhibitor list, the exhibitor search page or the show's homepage. The Actor:

  1. opens the page and finds which directory platform runs it,
  2. reads the event the page itself embeds (for example ISH on a Messe Frankfurt page, or the event and list ids of a Swapcard directory),
  3. scrapes that event's list.

Because the event comes from the page, a site that hosts several shows, cities or years never mixes them up: each link returns the edition it shows. The run log says what each link was matched to, and every record carries the link in exhibitionUrl.

Supported platforms: Messe Frankfurt (all its shows worldwide, e.g. Automechanika, Ambiente, Formnext, Intersec), Messe Düsseldorf VIS (MEDICA, drupa, K, interpack...), RX / Reed Exhibitions (World Travel Market, ISC West, MIPIM, Batimat, FIBO...), Map Your Show (hundreds of US shows: SEMA, NAB, IMTS, AHR, IPPE...), a2z and A2Z Connect (FABTECH, SuperZoo, Coverings, CEDIA, AIMExpo, American Coatings Show... including any <event>.smallworldlabs.com/exhibitors link), Swapcard directories (World Health Expo and many others), Corussoft event clouds (INTERNORGA, FRUIT LOGISTICA, InnoTrans, ILA), Koelnmesse (Anuga, ISM, ORGATEC, IDS, didacta, imm cologne, interzum, Kind + Jugend, spoga+gafa, FSB... paste the show's homepage or its list of exhibitors), NürnbergMesse (Embedded World, BIOFACH, Interzoo, Chillventa, FACHPACK, GaLaBau, Enforce Tac, POWTECH...), Newfront / ExpoPlatform marketplaces (EuroTier, Agritechnica, IMEX, Wine Paris, Vinexpo... paste the show's homepage or exhibitor directory), plus every built-in show. If a link isn't recognised, the run says so and charges nothing for it; open an issue with the link and we'll add the platform.

How to use it

  1. Pick one or more shows in Exhibitions, or paste links in Exhibitor list URLs (both work together).
  2. Optionally set Max exhibitors (try 20 first) and turn Include contact details off for a quick names-and-booths list.
  3. Press Start. Download results from the Output tab, or connect an integration (Google Sheets, HubSpot, Slack, webhooks).

maxResults applies per show. The older single-show field exhibitions ("exhibitions": "medica") still works and is combined with exhibitionList, so saved tasks and integrations keep running.

Contact details (Map Your Show)

Map Your Show lists only names and booths on its exhibitor pages; profile details sit one level deeper. With Include contact details on (the default), the Actor collects them inside your run:

  1. Exhibitors are written straight into your run's dataset, so you still get one dataset.
  2. You're billed once per exhibitor at the normal price, plus a tiny start fee (about $0.00005) for a second exhibition-scraper run you may see in your Runs list. It stops when your run stops.

Turn Include contact details off for a faster names-and-booths-only list.

Emails for every exhibitor

Many organisers list a company's website but not its email (Koelnmesse keeps it behind a login; Map Your Show, Newfront and NürnbergMesse often leave it out). Turn on Find emails on company websites and, for each exhibitor with a website but no email, the Actor reads the company's own site (home, contact and imprint pages) and adds the email, phone and social profiles it finds, marked contactSource: "company website". In a BIOFACH test, 11 of 20 exhibitors without an email got one. No extra charge; runs take longer.

Track changes before a show

Turn on Changes only and schedule the Actor (for example weekly in the months before a show). Each run returns only:

  • new exhibitors (changeType: "new"),
  • exhibitors whose booth, email, phone, website or address changed, with the old and new values: "changes": {"booth": {"old": "B12", "new": "C40"}},
  • exhibitors who dropped out of the list (changeType: "removed"; only when the whole list was read, so leave Max results empty).

Unchanged exhibitors are skipped and not charged. The first run returns everyone as new and becomes the baseline.

Use it in n8n, Make, Zapier, Clay or with other Actors

n8n (HTTP Request node):

  1. Add an HTTP Request node. Set Method to POST and URL to https://api.apify.com/v2/acts/tacps126~exhibition-scraper/run-sync-get-dataset-items.
  2. Set Authentication to Generic > Header Auth, with header Authorization and value Bearer YOUR_APIFY_TOKEN (Apify Console > Settings > API & Integrations).
  3. Turn on Send Body (JSON) and paste your input, e.g. {"startUrls": [{"url": "https://ish.messefrankfurt.com/frankfurt/en/exhibitor-search.html"}], "maxResults": 500}.
  4. Set Options > Timeout to 330000. This endpoint waits up to 5 minutes; for bigger lists, start the run with /runs and read the dataset afterwards.
  5. n8n turns each exhibitor into one item. Map {{ $json.name }}, {{ $json.booth }}, {{ $json.contact.email }}, {{ $json.contact.website }} and {{ $json.address.country }} into Google Sheets, HubSpot, Airtable or a database node.
  6. Optional: add an IF node on {{ $json.contact.email }} is empty, and send those rows' websites to Website Contact Details to find their emails.

n8n's Apify node, Make and Zapier work the same way: run tacps126/exhibition-scraper with your input, then read the run's dataset items. Ready-to-import n8n workflow (show > Google Sheet) and Make/Zapier steps: integrations guide.

Clay: Add data > Import from Apify > Actor run and pick a run of this Actor: each exhibitor becomes a row. Then enrich the rows with Clay's own providers, or with Run Apify Actor > tacps126/contact-details and input {"startUrls": [/Website]} for emails the show didn't publish.

Chain Actors in Apify Console:

  1. On this Actor's or task's Integrations tab, choose Connect Actor or task and pick Website Contact Details.
  2. Give it this run's dataset as datasetId.
  3. It reads contact.website from each exhibitor automatically, finds emails and phones on the company site, and carries name, booth and exhibition so you can join the results back.

CSV and Excel: nested fields become columns such as contact/email and address/city. Use the Overview or Contacts view for a flat table.

Python: see the exhibitor leads recipe. It scrapes a show by URL, fills missing emails with Website Contact Details and writes one CSV.

Questions

Questions about Trade Show Exhibitor List Scraper

How much does Trade Show Exhibitor List Scraper cost?

$3 per 1,000, charged only for exhibitors returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Trade Show Exhibitor List Scraper return?

Every row has the same fields, including name, exhibition, exhibitionUrl, booth, contact, address, social, categories. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_trade_show_exhibitors.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
