Guide

How Sports Betting Odds works

Inputs, options and tips, from the tool's own documentation.

Betting lines for the NFL, NBA, NHL, MLB, WNBA, college football and basketball, and European football (Premier League, LaLiga, Bundesliga, Serie A, Ligue 1, Champions League and more): moneyline, point spread and total with their prices, opening vs current lines, closing lines once the game is over, line movement, the no-vig win probability, and how each line settled (who covered, over or under, did the favourite win). Schedule it hourly to catch every line move.

Built for sports bettors and handicappers, picks and odds sites, model builders and quants, sports media and newsletters, Discord and Telegram bots, and AI agents.

Why this Actor

  • Opening, current and closing lines side by side, with movement already worked out.
  • Settled for you: cover, over/under and favourite results on finished games, ready for backtests.
  • Fair probability with the bookmaker margin removed.
  • 19 leagues, one shape: US pro and college sports plus the top European football leagues.
  • Line moves once: Only new + an hourly schedule returns a line again only when it changes.
  • For AI agents. Callable as an MCP tool.

Pricing

$3 per 1,000 odds rows (one game's lines from one sportsbook), plus a small start fee per run. On the Apify free plan a run returns up to 100 rows.

Good to know

  • Lines appear once the sportsbook posts them: NFL lines for the whole week, most other leagues on game day.
  • Odds are American (e.g. -110, +154). Probabilities are 0 to 1.
  • Need player stats, standings or rosters? Sports Data (tacps126/sports-data) covers 24 leagues with the same fields.
  • Odds are for research and analysis, not a live trading feed.

Questions

Questions about Sports Betting Odds

How much does Sports Betting Odds cost?

$3 per 1,000, charged only for odds line or games returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Sports Betting Odds return?

Every row has the same fields, including league, name, date, homeTeam, awayTeam, status, state, sportsbook, lineType (current or closing), details, homeMoneyline, awayMoneyline, drawMoneyline + ...Open, homeSpread, homeSpreadOdds, awaySpreadOdds, homeSpreadOpen, spreadMove, total, overOdds, underOdds, totalOpen, totalMove, favorite, favoriteAtOpen, homeWinProbability, awayWinProbability, homeScore, awayScore, spreadResult, totalResult, favoriteWon. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
