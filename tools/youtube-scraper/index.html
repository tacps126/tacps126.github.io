Guide

How YouTube Scraper works

Inputs, options and tips, from the tool's own documentation.

Scrape YouTube videos, Shorts and live streams from searches, channels and playlists with their views, likes, comment count, publish date, length, hashtags and description, plus each channel's subscribers, country, join date, total views and videos, and links. Use YouTube's own search filters and channel order (Latest, Popular, Oldest).

Built for influencer and creator research, competitor and brand monitoring, content and trend analysis, marketing and agency reporting, and datasets for AI and analytics.

How to use it

json
{
  "searchQueries": ["air fryer review"],
  "startUrls": [
    "https://www.youtube.com/@Fireship",
    "https://www.youtube.com/playlist?list=PLrAXtmErZgOeiKm4sgNOknGvNjby9efdf",
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
  ],
  "maxResults": 20,
  "maxResultsShorts": 10,
  "sortVideosBy": "POPULAR",
  "dateFilter": "month",
  "sortingOrder": "views"
}
  • Searches with YouTube's filters. Sort by relevance, rating, upload date or views; upload date (last hour to this year); type; length; HD, 4K, subtitles, Creative Commons, live, 3D, 360, VR180, HDR, location, purchased. Search page links work too.
  • Channels. Paste a @handle or channel link. Pick how many videos, Shorts and live streams to take, in Latest, Popular or Oldest order.
  • Playlists and single videos. Paste the links or video ids.
  • Date filter. oldestPostDate keeps only videos published after a date (2025-01-31) or within a period (7 days, 3 months). Older videos are not charged.
  • Channel details. On by default; each channel's About panel is read once and added to all its videos. Turn it off if you only need the videos.
  • Follow new uploads. Turn on Only new videos and schedule the Actor: each run returns only videos earlier runs haven't delivered.

Questions

Questions about YouTube Scraper

Does it need a YouTube API key or a login?

No.

Why is a video missing?

It is private, removed or restricted, or older than your date filter. The run summary says which.

Are like and comment counts exact?

Likes are exact. Comment and subscriber counts are as precise as YouTube shows them (YouTube rounds large numbers).

How much does YouTube Scraper cost?

$2 per 1,000, charged only for videos returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does YouTube Scraper return?

Every row has the same fields, including id, url, type, title, description, keywords, hashtags, viewCount, likes, commentsCount, date, uploadDate, durationSeconds, duration, category, thumbnailUrl, isLiveContent, isLiveNow, liveStart, liveEnd, isFamilySafe, isUnlisted, isMembersOnly. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
