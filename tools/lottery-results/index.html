Build the input, get the call

Change any field; the code on the right follows. Copy it, or run the same input on Apify.

Which lotteries to read. Powerball and Mega Millions are drawn nationwide; the others are New York or Texas games.

One row per draw, or one row per number with how often and how recently it was drawn in the date range.

Draws from this many days back. Default 30 for draws, 365 for number frequency.

Date range

YYYY-MM-DD. Overrides Days back. History goes back to 1980 (Numbers, Win 4), 1992 (Lotto Texas, Take 5), 2002 (Mega Millions) and 2010 (Powerball).

YYYY-MM-DD. Default today.

Most rows to return, shared fairly across games.

Monitoring

Schedule the Actor and each run returns only draws earlier runs did not deliver (draws only).

Python · pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("tacps126/lottery-results").call(run_input={

})

    print(item)
JavaScript · npm i apify-client
