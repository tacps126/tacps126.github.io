Guide

How Lottery Results works

Inputs, options and tips, from the tool's own documentation.

Winning numbers for 13 US lottery games in one table: Powerball (with Double Play), Mega Millions, Millionaire for Life, Cash4Life, NY Lotto, Take 5, Pick 10, Numbers, Win 4, Quick Draw, Lotto Texas, Texas Two Step and Cash Five. Draws come with the estimated jackpot and jackpot winners where published, history goes back to 1980, and a number frequency mode gives hot and cold numbers for any date range.

Built for lottery apps and websites, number-analysis and stats sites, newsletters and chat bots, researchers, and AI agents.

Why this Actor

  • 13 games, one shape: nationwide jackpot games plus New York and Texas games.
  • Jackpots and winners, not only numbers.
  • Hot and cold numbers for any period, with the even-odds share to compare against.
  • Deep history: Numbers and Win 4 from 1980, Lotto Texas and Take 5 from 1992, Mega Millions from 2002, Powerball from 2010.
  • New draws once: Only new + a schedule returns each draw a single time.
  • For AI agents. Callable as an MCP tool.

How to use it

Latest Powerball and Mega Millions draws with jackpots:

json
{ "games": ["powerball", "mega-millions"], "daysBack": 14 }

Hot and cold Powerball numbers over the last year:

json
{ "games": ["powerball"], "dataType": "stats" }

Every Win 4 draw in 2025:

json
{ "games": ["ny-win-4"], "dateFrom": "2025-01-01", "dateTo": "2025-12-31" }

New draws feed for a bot (schedule daily):

json
{ "games": ["powerball", "mega-millions", "millionaire-for-life", "ny-lotto", "lotto-texas"], "daysBack": 3, "onlyNew": true }

Pricing

$3 per 1,000 rows (draws or number-frequency rows), plus a small start fee per run. On the Apify free plan a run returns up to 100 rows.

Good to know

  • Results come from the official state lottery publications and usually appear within a day of the draw.
  • Quick Draw runs every four minutes; times after midnight count on the same draw day and run past 24:00 (e.g. 27:24 = 3:24 am).
  • Frequency uses each game's current number range; numbers never drawn in the range show timesDrawn: 0.
  • Cash4Life ended in February 2026; its history stays available.
  • Lottery draws are random: frequency describes the past and does not predict the next draw.

Questions

Questions about Lottery Results

How much does Lottery Results cost?

$3 per 1,000, charged only for draw or numbers returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Lottery Results return?

Every row has the same fields, including game, gameName, region, drawDate, drawTime, drawNumber, numbers, bonus, bonusName, multiplier, doublePlayNumbers, doublePlayBonus, result, jackpot, jackpotText, jackpotWinners, rolledOver, currency. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_lottery_results.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
