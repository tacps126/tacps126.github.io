Guide

How Trustpilot Reviews Scraper works

Inputs, options and tips, from the tool's own documentation.

Extract customer reviews and full company details from any Trustpilot company profile into clean, structured data - ratings, review text, reviewer info, dates, verification, company replies, TrustScore, and more. Fast, reliable, and pay-per-result.

What it does

Give it one or more companies (a domain like apify.com, or a full Trustpilot review URL) and it returns their reviews plus a company-details record (TrustScore, total reviews, reply metrics, contact info, categories) as structured records you can export to JSON, CSV, or Excel, push to your database, or feed into another Actor.

Features

  • 🔎 Multiple companies in a single run
  • 🏢 Company details - TrustScore, review counts, reply rate, contact info, categories
  • ⭐ Star / language / date / verified filters and free-text search
  • ↕️ Sort by most recent or most relevant
  • 👤 Rich reviewer data - name, country, review count, profile image, verified
  • 💬 Company replies - text and date
  • 🧹 Deduplication - no repeated reviews
  • 🔔 New-review monitoring - schedule it and get only reviews you haven't seen
  • 🔌 Instant API mode - get reviews straight back from a web request
  • ⚡ Fast & low cost - quick runs, low pay-per-result pricing, and no proxy needed by default

Why this scraper

  • Works out of the box. No proxy or extra setup needed for normal runs.
  • Low platform cost. You pay mostly for reviews, not machine time.
  • Handles rate limits for you. When Trustpilot says "slow down" (HTTP 429) the Actor waits as long as asked and continues; errors, timeouts and dropped downloads are retried automatically.
  • Never loses or double-bills work. Reviews are saved as each company finishes; if the platform moves your run to another server it resumes without charging twice, and it stops cleanly at your maximum charge.
  • Ready-to-analyze data. Every review comes with sentiment, reviewer country, reply time in days and text length - no post-processing needed.

Monitor new reviews

Turn on onlyNew and schedule the Actor (e.g. hourly or daily): each run returns only reviews posted since the previous runs, and you pay only for those. Great for alerting on new negative reviews (starRatings: ["1","2"] + onlyNew) - connect an Apify integration (Slack, email, Google Sheets, webhooks) to get them delivered automatically.

Use it as an instant API

The Actor also runs in Standby mode: an always-ready web endpoint that returns reviews directly in the response - handy for apps, dashboards, and AI agents. Find the endpoint URL on the Actor's Standby tab and call it with your Apify API token:

bash
curl "https://<standby-url>/?company=apify.com&maxReviews=20&sort=recency" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>"

Any input field works as a query parameter (or POST the input as JSON). The response looks like {"success": true, "count": 21, "items": [ ... ]} - the company record plus its reviews. Pricing is the same per review.

How to use

  1. Add the companies you want reviews for.
  2. Set optional filters (maxReviews, stars, language).
  3. Run the Actor, then download the results as JSON / CSV / Excel, or use the dataset API.

A proxy is not required - the Actor works out of the box. You can optionally enable an Apify proxy under Proxy if you want to route traffic through specific regions.

Pricing

Pay per result: you're charged per review delivered. Company-details records are free. See the Pricing tab for the current rate, and set a maximum charge on the run to cap spend - the Actor stops cleanly at your limit and keeps everything collected so far.

On Apify's free plan each run returns up to 500 reviews - plenty to try everything. Any paid Apify plan removes the limit.

Notes & tips

  • Provide either a bare domain (apify.com) or a full review URL - both work.
  • Higher maxReviews values take longer and cost more; start small to preview.
  • If a company has few or no reviews, the run simply returns fewer items.
  • Use maxReviewsPerCompany when scraping many companies so each gets its share.
  • Listing the same company twice is fine - it's fetched once.
Questions

Questions about Trustpilot Reviews Scraper

How much does Trustpilot Reviews Scraper cost?

$0.55 per 1,000, charged only for reviews returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Trustpilot Reviews Scraper return?

Every row has the same fields, including reviewId, company, url, rating, title / text, language, author / authorId, authorCountry / authorReviewCount. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_trustpilot_reviews.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
