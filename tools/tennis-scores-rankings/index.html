Guide

How Tennis Scores works

Inputs, options and tips, from the tool's own documentation.

ATP and WTA tennis in one table: results and live scores with set-by-set scores and tiebreaks, the order of play for the coming days, singles and doubles, walkovers and retirements, plus ATP and WTA singles rankings with points and moves. Filter by player, draw and status, export to JSON, CSV or Excel, or schedule it to get each result once.

Built for tennis bettors and modellers, fantasy players, tennis media and newsletters, app and bot builders, researchers, and AI agents.

Why this Actor

  • Men's and women's tours, singles and doubles, with the same fields.
  • Set scores and tiebreaks, plus walkovers and retirements marked in status.
  • Fixtures too: days ahead for the coming order of play.
  • Rankings with points and weekly moves.
  • Results once: Only new + a daily schedule returns each match again only when its status changes, so finals arrive once.
  • For AI agents. Callable as an MCP tool.

How to use it

Yesterday's and today's finished singles matches:

json
{ "daysBack": 1, "gameStatus": "final", "matchType": "singles" }

The next three days' matches:

json
{ "daysBack": 0, "daysAhead": 3, "gameStatus": "scheduled" }

Every match Sinner and Swiatek played this season:

json
{ "dateFrom": "2026-01-01", "teams": ["Sinner", "Swiatek"] }

Current ATP and WTA singles rankings:

json
{ "dataType": "standings" }

Options

OptionWhat it does
Tours (leagues)atp, wta
Data (dataType)games (matches) or standings (rankings)
Days back / Days ahead (daysBack, daysAhead)Rolling window: daysBack: 1 = yesterday and today; daysAhead: 3 = the next three days

Match status (gameStatus)any, final, live or scheduled

Draw (matchType)any, singles or doubles
Max results (maxItems)Most rows per run
Only new (onlyNew, monitorName)With a schedule, each run returns only rows earlier runs did not deliver; a match comes again when its status changes

Questions

Questions about Tennis Scores

How much does Tennis Scores cost?

$3 per 1,000, charged only for match or ranking rows returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Tennis Scores return?

Every row has the same fields, including league (ATP, WTA), eventName, venue, draw, session, date, status, state (pre, in, post), completed, statusDetail, name, winner, result, competitors, eventId, competitionId, url. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
