Guide

How Job Board Harvester works

Inputs, options and tips, from the tool's own documentation.

Pull job postings from company career pages, AI talent marketplaces, and the big job search boards into a single, normalized, deduplicated dataset - ready to export to JSON, CSV, or Excel, push to your database, or feed into another Actor.

Track hiring at the companies you care about, build a jobs feed, power a recruiting tool, or run market research - without wiring up a dozen different sites yourself.

What it does

Ways to source jobs, mixed freely in one run:

  • Company boards - paste a company's careers page (https://www.figma.com/careers) or just its name (Datadog): the job board behind it is found automatically and every open role comes back.
  • The company directory - scan our directory of 500+ verified company boards (about 195,000 open jobs at the last refresh) on the systems you pick, biggest first, and filter by title, location and country. No company list needed.
  • AI & remote talent marketplaces - Mercor, micro1, Turing and Himalayas: expert, AI-training and remote roles, often with hourly rates.
  • Tech and startup job search - Dice, Built In and Wellfound (salary and equity), no login needed.
  • Open job feeds - Remote OK, Jobicy and Working Nomads (remote jobs), Arbeitnow (Germany and Europe) and Y Combinator's startup job board (with salary, equity and YC batch). Every job links back to its original page.
  • Search boards - search by keyword, location, and filters across thousands of companies.

Every posting comes back in the same shape no matter where it came from, enriched with a work-mode (remote / hybrid / on-site), a seniority level, and a parsed salary - so results from Greenhouse, LinkedIn, and Workday all line up in one table.

Why this harvester

  • Fast. A company's whole board typically comes back in about a second - 200 jobs in under 2 seconds on the platform.
  • Costs almost nothing to run. Platform usage for a typical run is a fraction of a cent. You pay for results, not machine time.
  • Starts instantly. A tiny container means runs begin in seconds, and the always-on API mode answers with no start-up wait at all.
  • Handles rate limits for you. When a board says "slow down" (HTTP 429) the Actor waits exactly as long as asked and carries on; server errors, timeouts and dropped downloads are retried automatically, and request speed adapts per site.
  • Never loses or double-bills work. Results are saved as each source finishes. If the platform moves your run to another server it resumes where it stopped without charging twice, and it stops cleanly at your maximum charge, keeping everything collected so far.
  • One clean format for every board. Structured location with ISO country code, remote/hybrid/on-site (only when the posting says so), employment type, seniority, experience, job function, skills and salary annualized for comparison - identical columns whether a job came from Greenhouse, Workday or LinkedIn.
  • 13 job-board systems. Greenhouse, Lever, Ashby, Workday, SmartRecruiters, Workable, Rippling, BambooHR, Pinpoint, Breezy, Recruitee, Personio and Teamtailor - more than any other career-site scraper on the Store.
  • Simple setup. Paste career-page links or company names and press Start. No API keys or logins for any of the "works out of the box" boards.

Only need one board? There's a focused, simpler Actor for each: Greenhouse, Lever, Ashby, Workday, SmartRecruiters, Recruitee, Personio, Teamtailor, LinkedIn, Himalayas and AI training jobs (Mercor, micro1, Turing).

Monitor new jobs on a schedule

Turn on onlyNew and schedule the Actor (e.g. daily). Each run delivers only postings that earlier runs haven't - you're charged only for new jobs. Use a different monitorName per monitor if you run several. Pair it with an Apify integration (Slack, email, Google Sheets, webhooks) to get new jobs delivered automatically.

Changes only goes one step further: each run returns new jobs, jobs whose salary, location, title or work mode changed (with the old and new values), and jobs that were taken down (changeType: "removed"), a ready signal of what a company stopped hiring for. Unchanged jobs are free.

Use it as an instant API

The Actor also runs in Standby mode: an always-ready web endpoint that returns jobs directly in the response - ideal for apps, spreadsheets, and AI agents. Find the endpoint URL on the Actor's Standby tab and call it with your Apify API token:

bash
curl "https://<standby-url>/?platform=greenhouse&company=stripe&titleIncludes=engineer&maxItems=20" \
  -H "Authorization: Bearer <YOUR_APIFY_TOKEN>"

Pass any input field as a query parameter (a single source can be given flat, as above), or POST the full input as JSON. The response looks like {"success": true, "count": 20, "items": [ ... ]}. Pricing is the same per job.

About referral links

Several talent marketplaces reward members who refer candidates. Where the Actor's maintainer has a referral link for a board, jobs from that board carry an extra referralUrl field - applying through it may credit the maintainer, at no cost to the candidate. The posting itself, url, and applyUrl are never changed, and you can leave the field out entirely with includeReferralLinks: false.

More boards with your own access

Some boards - Naukri, Monster, and LinkedIn beyond public search - guard their listings behind a login or anti-bot protection. You can open them by letting the Actor use your own access. Add either of these to any source:

Using your own sign-in - for boards that only show jobs to signed-in users, pass your own session as sessionCookies. The Actor collects jobs through your authenticated session, exactly as you'd see them.

json
{ "platform": "naukri", "query": "rust developer", "location": "bangalore",
  "sessionCookies": "<what you copied, see below>" }

How to copy it (Chrome, Edge or Firefox):

  1. Sign in to the board in your browser.
  2. Press F12 (Mac: Cmd+Option+I) and open the Network tab.
  3. Reload the page (F5) and click the first request in the list.
  4. Right-click it and choose Copy > Copy as cURL (bash) (Firefox: Copy Value > Copy as cURL).
  5. Paste the whole text as the value of sessionCookies (for one board: {"naukri": "<paste>"} in the secret field, or sessionCookies on a source).

The plain Cookie header (name=value; name2=value2), the JSON export of a cookie extension and a cookies.txt file work too. Cookies for other websites are ignored.

It is a password: use your own account, ideally a separate one. It is stored encrypted, never appears in your results or logs, and signing out in your browser ends that session. We never ask for your password or sign in for you. If what you pasted is a web address, empty, or expired, the run stops at the start and says which, at no cost. The board's terms apply to your account.

Your access key - if you have an API key for the board, or a key from a web-unlock provider, pass it under headers and it's applied to every request for that source.

json
{ "platform": "monster", "query": "data engineer",
  "headers": { "x-api-key": "your-key" } }

Your credentials are used only for your own run to fetch data you already have access to.

Pricing

Pay per result: you're charged per job posting delivered - nothing for filtered-out, duplicate, or (with onlyNew) already-seen jobs. See the Pricing tab for the current rate. Set a maximum charge on the run to cap spend.

On Apify's free plan each run returns up to 500 jobs - plenty to try everything. Any paid Apify plan removes the limit.

Tips

  • Start with a small maxItems to preview results, then scale up.
  • Set a maximum charge on the run to cap spend - the Actor stops cleanly at your limit and keeps everything collected so far.
  • Results are saved as each source finishes, so a long run that times out still keeps its data.
  • For the search boards, enabling a proxy improves reliability.
  • Company sources need the company name exactly as it appears in its jobs-page address.
  • If a run is interrupted by the platform, it picks up where it left off without charging twice.
Questions

Questions about Job Board Harvester

How much does Job Board Harvester cost?

$1.60 per 1,000, charged only for jobs returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Job Board Harvester return?

Every row has the same fields, including title, company / companySlug, companyLogo, location / locations, city / region / country / countryCode, workMode / remote, employmentType, seniority. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_company_jobs.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
