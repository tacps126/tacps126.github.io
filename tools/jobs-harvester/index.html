Build the input, get the call

Change any field; the code on the right follows. Copy it, or run the same input on Apify.

The quickest way to start: paste careers pages — the company's own (`https://www.figma.com/careers`) or its job board (`https://jobs.lever.co/palantir`, a Workday careers page). The job board behind the page is found automatically. Works…

Just type company names (`Datadog`, `Ramp`). Each is looked up on every supported job board system; the board with the most open jobs is used, and other matches are listed in the run's warnings. A careers URL is more precise when a name is…

Also scan our directory of verified company job boards on these systems, biggest boards first — no company list needed. Combine with the title, location and country filters below.

How many directory boards to scan in one run (boards alternate between the selected systems).

Skip directory companies with fewer open jobs than this (as of the last directory refresh).

Maximum total job postings to emit across all sources.

Optional cap per board/search, so one large company or marketplace can’t use up the whole “Max items”.

Normalize every job into one schema: structured location + country code, work mode, employment type, seniority, years of experience, job function, skills, annualized salary, education and visa signals.

Drop duplicate postings (by url + title + company).

Open each job’s own page for extra fields where the list is thin (e.g. LinkedIn: full description, seniority, employment type, applicant count). Slower — one extra request per job — and only done for jobs that pass your filters.

Filters

Keep a job only if its title contains any of these words (case-insensitive), e.g. `engineer`, `developer`.

Drop a job whose title contains any of these words (case-insensitive), e.g. `intern`, `manager`.

Keep a job only if its location contains any of these (case-insensitive), e.g. `Berlin`, `Remote`.

Keep only jobs in these countries: 2-letter codes (`US`, `GB`, `DE`, `IN`) or names. The country comes from the board when it gives one, otherwise from the location text.

Keep only jobs posted in the last N days. Jobs whose board doesn't publish a date are kept.

Keep only remote jobs (uses the normalized `workMode`; requires Enrich).

Keep only these work arrangements. Jobs whose posting doesn't state it are dropped when this is set.

Keep only these employment types.

Keep only these seniority levels.

Keep only these job functions (engineering, data, sales, …).

Keep a job only if its title, description or skills mention any of these, e.g. `Kubernetes`, `Python`, `SQL`.

Drop jobs from companies whose name contains any of these, e.g. staffing agencies.

Keep jobs paying at least this per year (hourly and monthly pay are converted), in the posting's currency. Jobs that don't publish pay are kept unless “Only jobs with salary” is on.

Keep only jobs that publish their pay.

Keep only jobs whose posting says visa sponsorship is available.

Monitoring

Emit only jobs that no earlier run with the same sources (or the same state key) has already delivered. Ideal for scheduled runs — you pay only for new results.

Return only jobs that are new, changed or closed since the last run with the same input (or monitor name): changed jobs carry `changeType: "changed"` and `changes` with the old and new salary, location, title or work mode; jobs taken down…

Some marketplaces pay referral bonuses. When available, jobs get an extra `referralUrl` that may credit the Actor’s maintainer. Job links and `applyUrl` are never changed. Turn off to omit the field.
