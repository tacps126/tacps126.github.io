Guide

How Prediction Markets works

Inputs, options and tips, from the tool's own documentation.

Live odds from the four biggest prediction markets in one table: Kalshi, Polymarket, Manifold and PredictIt. Every market comes back with its probability, bid and ask, 24-hour change, volume, liquidity, open interest, close date and, once settled, the result. Search by keyword or category, paste market links, add daily price history, and schedule it to get an alert row whenever a market moves by the points you choose.

Built for traders and forecasters, journalists and newsletters, quant and research teams, app and bot builders, and AI agents.

Why this Actor

  • Four platforms, one shape. Compare the same question across Kalshi, Polymarket, Manifold and PredictIt without four parsers.
  • Search and categories. Keywords (fed rate, bitcoin, world cup) or 14 categories: politics, elections, economics, finance, crypto, sports, tech and science, AI, climate and weather, culture, world, companies, health, mentions.
  • Paste links. Kalshi tickers or links, Polymarket event or market links, Manifold links, PredictIt links or ids.
  • Move alerts. Set Alert on moves to e.g. 5 and schedule hourly: each run returns only markets whose probability moved 5+ points since you last got them, with the old and new price.
  • Price history. Daily probability for up to a year per market, ready to chart.
  • Settled markets too. Status closed returns resolved markets with the winning outcome.
  • For AI agents. Callable as an MCP tool.

How to use it

Busiest markets on Kalshi and Polymarket right now:

json
{ "platforms": ["kalshi", "polymarket"], "maxItems": 50 }

Every Fed-rate market on all four platforms, with 30 days of history:

json
{ "platforms": ["kalshi", "polymarket", "manifold", "predictit"], "search": "fed rate", "historyDays": 30 }

Elections closing in the next 14 days, biggest movers first:

json
{ "categories": ["elections"], "closesWithinDays": 14, "sortBy": "move24h" }

Alert when any big crypto market moves 5 points (schedule hourly):

json
{ "platforms": ["kalshi", "polymarket"], "categories": ["crypto"], "minVolume24h": 10000, "alertMovePoints": 5 }

Specific markets by link:

json
{ "markets": ["https://polymarket.com/event/fed-decision-in-december-20260729232808632", "KXFEDDECISION-26DEC"] }

Pricing

$3 per 1,000 markets, plus a small start fee per run. Price history is included. On the Apify free plan a run returns up to 100 markets.

Good to know

  • Volume units differ: Kalshi counts contracts, Polymarket US dollars, Manifold play money (MANA). volumeUnit says which; the volume filters apply in each platform's own unit.
  • Manifold is play money; its probabilities are still a useful crowd forecast.
  • PredictIt lists politics only and shows no volume, so it is left out when a volume or liquidity minimum is set.
  • Sorting by volume or liquidity takes the top of each platform in turn, since units differ; closing soon, newest and biggest move sort across all.
  • The first alert run returns every match as the baseline; later runs return only moves (and markets that are new to the search).
  • Prices are delayed snapshots for research, not a trading feed.

Questions

Questions about Prediction Markets

How much does Prediction Markets cost?

$3 per 1,000, charged only for markets returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Prediction Markets return?

Every row has the same fields, including platform, marketId, eventId, eventTitle, question, outcome, url, probability, lastPrice, yesBid, yesAsk, noBid, noAsk, spread, change24h, change7d, volume, volume24h, volumeUnit, openInterest, liquidity, traders, outcomes, category, openTime, closeTime, status (open, closed, resolved), result, resolutionStatus, rules. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_prediction_markets.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
