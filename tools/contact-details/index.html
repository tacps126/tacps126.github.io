Questions

Questions about Website Email Finder & Contact Details Scraper

How much does Website Email Finder & Contact Details Scraper cost?

$1.75 per 1,000, charged only for website with contactss returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as find_website_contacts and find_local_businesses.
