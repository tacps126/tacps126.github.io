Guide

How Polymarket Scraper works

Inputs, options and tips, from the tool's own documentation.

Every Polymarket market you need in one table: probability, every outcome's price, bid and ask, 24-hour and 7-day change, volume, liquidity, close date, resolution status and, once settled, the result. Search by keyword or category, paste event links, add daily price history, and schedule it to get an alert row whenever a market moves by the points you choose.

Built for traders and forecasters, journalists and newsletters, quant and research teams, app and bot builders, and AI agents.

How to use it

Busiest Polymarket markets right now:

json
{ "maxItems": 50 }

Fed-rate markets with 30 days of history:

json
{ "search": "fed rate", "historyDays": 30 }

Crypto markets with $10,000+ traded today, biggest movers first:

json
{ "categories": ["crypto"], "minVolume24h": 10000, "sortBy": "move24h" }

Alert when any politics market moves 5 points (schedule hourly):

json
{ "categories": ["politics"], "minVolume24h": 5000, "alertMovePoints": 5 }

Specific events by link:

json
{ "markets": ["https://polymarket.com/event/fed-decision-in-december-20260729232808632"] }

Pricing

$3 per 1,000 markets, plus a small start fee per run. Price history is included. On the Apify free plan a run returns up to 100 markets.

Good to know

  • Categories: politics, elections, economics, finance, crypto, sports, tech and science, AI, climate and weather, culture, world, companies, health.
  • A finished game or event shows as closed while its result is being confirmed, and as resolved with result once settled.
  • The first alert run returns every match as the baseline; later runs return only moves (and new markets).
  • Need Kalshi, Manifold or PredictIt too? Prediction Markets (tacps126/prediction-markets) covers all four in one table.
  • Prices are delayed snapshots for research, not a trading feed.

Questions

Questions about Polymarket Scraper

How much does Polymarket Scraper cost?

$3 per 1,000, charged only for markets returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Polymarket Scraper return?

Every row has the same fields, including marketId, conditionId, slug, eventId, eventTitle, question, outcome, url, probability, outcomes, lastPrice, yesBid, yesAsk, noBid, noAsk, spread, change24h, change7d, volume, volume24h, liquidity, category, openTime, closeTime, status (open, closed, resolved), resolutionStatus, result, rules. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
