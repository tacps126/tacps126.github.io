Guide

How Property Finder Scraper works

Inputs, options and tips, from the tool's own documentation.

Get property listings from Property Finder, the leading property portal in the Middle East, as a clean, spreadsheet-ready dataset: apartments and villas to rent or buy in the UAE (Dubai, Abu Dhabi...), Saudi Arabia, Qatar, Bahrain and Egypt. Each listing includes the price with its period (yearly rent or sale price) in the local currency, bedrooms, bathrooms, size in m² and sq ft, price per m², community and building, GPS coordinates, amenities, furnishing, the agent and broker with phone, WhatsApp and email, the verified badge, photos and the listing date. Export to JSON, CSV or Excel, send to Google Sheets, or call it as an API.

Built for real-estate investors and analysts in the Gulf, brokers and agencies watching competitors and pricing, relocation and proptech teams, and anyone who wants new listings the moment they appear.

Why this scraper

  • Five countries. propertyfinder.ae, .sa, .qa, .bh and .eg, each in its own currency (AED, SAR, QAR, BHD, EGP).
  • Fast and cheap. Results are read straight from Property Finder's pages without a browser.
  • Plain-word locations. Type Dubai Marina, Downtown Dubai, Riyadh or The Pearl. The Actor finds the matching area. Or leave it empty for the whole country, or paste any Property Finder search URL.
  • Broker contact included. Broker name, phone, WhatsApp and email, plus the agent's name, on every listing.
  • Analysis-ready. Size converted to m², price per m² computed, amenities as readable names (Balcony, Shared Pool, Maids Room...).
  • Filters. Rent or buy, apartments or villas, price range, bedrooms, newest first.
  • New-listing alerts. Schedule it with Only new listings and each run returns only listings you haven't received yet.
  • Price-change tracking. Turn on Changes only and schedule it: each run returns only listings that are new, whose price, rent, size, rooms or title changed (with the old and new values, e.g. "changes": {"price.amount": {"old": 1450, "new": 1395}}), or that were taken down (changeType: "removed"). Unchanged listings are skipped and not charged. Each changed listing also carries priceHistory (dated prices across runs).
  • Price-cut feed. Turn on Price drops only and schedule it daily: you get only listings whose price went down, with old and new price and the history.

How to use it

  1. Pick the Country, add Locations (e.g. Dubai Marina), and choose Rent or buy and Property type.
  2. Optionally set price and bedrooms filters and Sort by: Newest first.
  3. Press Start. Download results from the Output tab, or connect an integration.

Questions

Questions about Property Finder Scraper

Which countries?

United Arab Emirates, Saudi Arabia, Qatar, Bahrain and Egypt.

Is it legal?

The Actor collects publicly listed property ads. Broker contact details are business contacts published for enquiries; use them within the laws that apply to you.

How much does Property Finder Scraper cost?

$1 per 1,000, charged only for listings returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Property Finder Scraper return?

Every row has the same fields, including title, url, id, reference, offerType, propertyType, listingKind, price, bedrooms, studio, bathrooms, livingArea, sizeSqft, pricePerSqm, address, latitude, longitude, features, furnished. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
