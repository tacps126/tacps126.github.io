Guide

How Clinical Trials Scraper works

Inputs, options and tips, from the tool's own documentation.

Clinical trials from ClinicalTrials.gov (500,000+ studies worldwide) by condition, drug or intervention, sponsor and location, filtered by status, phase, study type and sponsor type. Each study comes with dates, enrollment, design, interventions, primary outcomes, eligibility, central contacts (name, phone, email), officials, and sites with city, country and coordinates.

Built for CROs and site networks, pharma and biotech business development, medtech and suppliers selling to trial sites, patient-recruitment firms, investors and analysts, and AI agents.

Why this Actor

  • Every filter that matters: condition, drug, sponsor, place, status, phase, study type, industry vs academic sponsor, newly posted or recently updated.
  • Contacts and sites in each row, ready for outreach or site mapping.
  • New-study alerts: Only new studies on a weekly schedule.
  • For AI agents. Callable as an MCP tool.

How to use it

Recruiting industry-sponsored phase 3 obesity trials:

json
{ "condition": "obesity", "statuses": ["RECRUITING"], "phases": ["PHASE3"], "sponsorTypes": ["INDUSTRY"] }

New oncology studies with a site in India, every week:

json
{ "condition": "cancer", "location": "India", "firstPostedWithinDays": 7, "onlyNew": true }

Questions

Questions about Clinical Trials Scraper

How much does Clinical Trials Scraper cost?

$3 per 1,000, charged only for studys returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Clinical Trials Scraper return?

Every row has the same fields, including nctId, url, title, officialTitle, acronym, status, startDate, primaryCompletionDate, completionDate, firstPosted, lastUpdated, whyStopped, sponsor, sponsorType, collaborators, organization, studyType, phases, enrollment, allocation, primaryPurpose, masking, conditions, keywords, interventions, primaryOutcomes, summary, eligibility, centralContacts, officials, countries, locationCount, locations. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_clinical_trials.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
