Guide

How Vimeo Scraper works

Inputs, options and tips, from the tool's own documentation.

Vimeo creators and videos in one table: followers, video count, location, bio, websites, e-mails and socials, skills, paid plan, available for hire, average plays and likes, engagement rate and a lead score, plus their videos with likes, comments, plays where shown, duration, tags and dates. Search finds both creators named after a term and the people making videos about it.

Built for brands and agencies looking for filmmakers and animators, video marketers, recruiters, researchers, and AI agents.

How to use it

Animators and filmmakers for a topic, with their latest 5 videos:

json
{ "searchTerms": ["motion design", "documentary"], "profilesPerSearch": 50, "itemsPerProfile": 5 }

Active creators open to work, posted in the last 3 months:

json
{ "searchTerms": ["3d animation"], "releasedWithinDays": 90, "mustHave": ["website"], "itemsPerProfile": 0 }

Single videos by link:

json
{ "startUrls": ["https://vimeo.com/76979871"] }

Questions

Questions about Vimeo Scraper

Why are plays empty?

Vimeo shows play counts only when the owner allows it; likes and comments are always there.

What is the lead score?

A 0 to 100 score for how well a creator fits for a brand deal or collaboration: 1k to 100k followers (+25; 100k to 1M +15), engagement of 3% or more (+20; 1 to 3% +10), a post in the last 30 days (+20; 90 days +10), an e-mail address (+20), accounts on two or more other platforms (+15). Results from each link or search are sorted by it, highest first.

How is engagement worked out?

From the latest videos or posts (at least 3, or all on one TikTok page): (average likes + average comments) divided by average views on YouTube and Vimeo, or by followers on Instagram and TikTok, in percent. TikTok lists views only on its latest videos, so likes there are the account's lifetime likes per video.

Is this legal?

It reads public profile and catalogue pages anyone can open without an account. Use the data in line with the platform's terms and privacy law where you are, especially for e-mail outreach.

Do I need an account, API key or cookies?

No.

Why is a value empty?

Each platform shows different numbers, and some profiles leave fields blank. Missing values are null, so columns always line up.

Free plan?

Free-plan runs are limited to a small number of results per month. Paid plans have no limit.

How much does Vimeo Scraper cost?

$1 per 1,000, charged only for profiles returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Vimeo Scraper return?

Every row has the same fields, including platform, id, url, username, name, verified, private, followers, following, videoCount, postsCount, totalViews, likesCount, avgViews, avgLikes, avgComments, engagementRate, latestRelease, isBusiness, businessCategory, country, bio, avatarUrl, headerImageUrl, createdAt.
