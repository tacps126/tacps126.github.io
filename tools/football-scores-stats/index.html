How to use it

This weekend's results in the top five leagues:

json
{ "leagues": ["premier-league", "la-liga", "bundesliga", "serie-a", "ligue-1"], "daysBack": 3, "gameStatus": "final" }

Champions League fixtures this week:

json
{ "leagues": ["champions-league"], "daysBack": 0, "daysAhead": 7, "gameStatus": "scheduled" }

Premier League table:

json
{ "leagues": ["premier-league"], "dataType": "standings" }

Opening and current betting lines for the weekend:

json
{ "leagues": ["premier-league", "la-liga"], "dataType": "odds", "daysBack": 0, "daysAhead": 3 }

Options

OptionWhat it does
Competitions (leagues)e.g. premier-league, la-liga, bundesliga, serie-a, ligue-1, champions-league, mls
Data (dataType)games, boxScores, odds, standings, teams or rosters

Only new (onlyNew, monitorName)With a schedule, each run returns only rows earlier runs did not deliver; a game comes again when its status changes

Questions

Questions about Football Scores

How much does Football Scores cost?

$3 per 1,000, charged only for game, standing, team or players returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Football Scores return?

Every row has the same fields, including Matches, Player stats, Odds, League tables, Clubs / squads. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
