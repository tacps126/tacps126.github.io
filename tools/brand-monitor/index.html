Guide

How Brand Monitor works

Inputs, options and tips, from the tool's own documentation.

Track what people say about a brand in one run: news articles, posts from X (Twitter), Instagram, TikTok, Threads and Bluesky, YouTube videos, Trustpilot reviews and App Store / Google Play reviews. Every mention comes back in one shape with its sentiment, and each run also saves a digest: how many new mentions per source, the sentiment split, the most engaging mentions and the most negative ones. Schedule it daily and only new mentions come back.

How to use

  1. Enter the Brand name and, if you like, extra Keywords (product names, the CEO) and Exclude words.
  2. Add the brand's own accounts (X, Instagram, TikTok, Threads, Bluesky, YouTube), its Trustpilot page and its apps to also get their newest posts and reviews. Sources with nothing to read are skipped.
  3. Press Start. Download the results as JSON, CSV or Excel, or send them to Slack, email, a webhook or Google Sheets.

{

Pricing

Pay per result, no subscription:

EventPrice
Mention$0.0008 (about $0.80 per 1,000)
Digest$0.02 per run that finds new mentions
Run start$0.005

You pay for each mention row and once for the digest; a run with nothing new pays only the start. A daily run that finds 100 new mentions costs about $0.11. With Only new mentions on, a mention is charged once, however many runs see it. The AI summary is optional and uses Apify's AI, billed to your Apify account.

Monitoring

Schedule the Actor (daily or hourly) with Only new mentions on (the default). Each run returns only mentions earlier runs did not deliver, plus a fresh digest. Use Monitor name to run several brands or clients side by side, and connect the run to Slack, email or Google Sheets in the Integrations tab for alerts.

Good to know

  • Sentiment is read from the words of each mention (and from the stars of reviews). It is a quick signal for sorting, not a final verdict; turn on the AI summary for themes and risks in plain words.
  • X, Instagram and TikTok posts come from the accounts you list (your own and competitors). Keyword search on those sites is not included. Facebook is not included: page posts are not public without an account.
  • News, Threads, Bluesky and YouTube are searched with your keywords; use Exclude words when the brand name is a common word.
  • If one source is unavailable during a run, the others still return and the digest lists the failed source.
Questions

Questions about Brand Monitor

Can I watch competitors too?

Yes. Run one task per brand with its own Monitor name, or add competitor accounts to the same run.

How far back does it go?

Up to 30 days (Last N days). For history, run it on a schedule and keep the dataset.

Can I get only reviews?

Yes. Set Sources to Trustpilot and App reviews.

How much does Brand Monitor cost?

$0.80 per 1,000, charged only for mentions returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Brand Monitor return?

Every row has the same fields, including source, title, text, author, publishedAt, sentiment, rating, likes. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as monitor_brand.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
