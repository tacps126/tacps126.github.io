Guide

How Alerts Radar works

Inputs, options and tips, from the tool's own documentation.

Official warnings from national weather and disaster services in one clean schema: floods and heavy rain, storms and cyclones, lightning, heat, cold, drought, wildfires, earthquakes, tsunamis and volcanoes. Filter by country, hazard, severity and area; schedule it and get only new alerts as a dataset, an RSS feed, a Slack message or rows in Google Sheets.

Built for logistics and supply-chain teams, insurers and risk analysts, agriculture and energy operators, travel and event companies, field-service and facility managers, newsrooms, and AI agents that need to know where the weather is turning dangerous.

All are official public feeds built on the Common Alerting Protocol (CAP). No logins, no keys.

Why this Actor

  • One schema for every service. event, hazard, severity, urgency, certainty, headline, description, instruction, areas, sentAt, onset, expires, sender, url, plus magnitude and point for earthquakes.
  • Hazard types across languages. "Tempestade", "Gewitter", "Flash Flood Warning" and "Squally weather" all land in one hazard value (storm, flood, heat, cold, drought, fire, earthquake...).
  • Only what matters. States or provinces (pick from the list or type Kerala, Texas, IN-MH; misspellings get a suggestion), minimum severity (moderate by default), hazards, district or city names and keywords; expired alerts are left out.
  • Alert feeds. Turn on Only new alerts and schedule it every 15 minutes or hourly: each run returns only what earlier runs didn't deliver. Follow the Standby URL with &format=atom in any feed reader, or send results to Slack, Discord, Google Sheets or a webhook.
  • For AI agents. Callable as an MCP tool.

Pricing

$2 per 1,000 alerts plus a small start fee per run. Alerts that don't match your filters, and (with Only new alerts) alerts already delivered, are free.

Good to know

These are copies of official warnings for monitoring and analysis, not an emergency notification service: always follow the issuing authority. When you republish alerts, show the attribution and the issue time and link to the source. MeteoAlarm asks redistributors to publish: "Time delays between this website and the www.meteoalarm.org website are possible. For the most up-to-date awareness information as published by the participating National Meteorological and Hydrological Services, please refer to www.meteoalarm.org."

Questions

Questions about Alerts Radar

How much does Alerts Radar cost?

$2 per 1,000, charged only for alerts returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Alerts Radar return?

Every row has the same fields, including sentAt, onset, expires, country, subdivisions, areas, point, event, hazard, categories, severity, urgency, certainty, headline, description, instruction, messageType, sender, attribution, url. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_alerts.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
