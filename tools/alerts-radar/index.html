Alerts Radar — Weather & Disaster Warnings

Official weather and disaster warnings in one schema: US National Weather Service, MeteoAlarm (38 European countries), India NDMA, Brazil INMET, GDACS and USGS. Floods, storms, heat, drought, earthquakes; severity and area filters, only-new alerts.

Build the input, get the call

Change any field; the code on the right follows. Copy it, or run the same input on Apify.

ISO codes or names, e.g. IN, US, BR, DE, or EU for every MeteoAlarm country. Empty = every country the sources cover. Worldwide sources (GDACS disasters, USGS earthquakes) are filtered to these countries.

Only these hazard types. Empty = all.

CAP severity as set by the issuing service.

Keep alerts whose area names contain any of these (a state, district, county or city, e.g. Kerala, Texas, Bayern). Empty = all areas.

Whole words matched on the event, headline, description and areas.

Leave out alerts whose expiry time has passed.

CAP updates and cancellations of earlier alerts are kept, flagged in `messageType`.

Only alerts issued in this window.

Pick specific services instead of countries.

Most alerts returned by the run (most severe first).

Monitoring

Schedule the Actor (every 15 minutes to daily) and each run returns only alerts earlier runs didn't deliver: an alert feed you pay for only when something new is issued.

terminal
curl -X POST \
  "https://api.apify.com/v2/acts/tacps126~alerts-radar/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"countries":["IN","US"]}'
Python · pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("tacps126/alerts-radar").call(run_input={
    "countries": ["IN", "US"],
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
JavaScript · npm i apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });
const run = await client.actor('tacps126/alerts-radar').call({
  "countries": [
    "IN",
    "US"
  ]
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);
