Guide

How FDA 510(k) & PMA Device Clearances works

Inputs, options and tips, from the tool's own documentation.

New FDA medical device decisions in one clean feed: 510(k) clearances and PMA approvals, each with the applicant company, the contact person (510(k)), address, device and generic name, product code, review specialty, device class, dates received and decided, review time in days, decision and links to the FDA record and summary.

Built for medtech sales and business development (newly cleared devices = companies about to launch), regulatory consultants, contract manufacturers and component suppliers, investors and analysts, and AI agents.

Questions

Questions about FDA 510(k) & PMA Device Clearances

How much does FDA 510(k) & PMA Device Clearances cost?

$4 per 1,000, charged only for decisions returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does FDA 510(k) & PMA Device Clearances return?

Every row has the same fields, including type, id, url, documentUrl, applicant, contact, street, city, state, zip, country, deviceName, genericName, productCode, deviceClass, regulationNumber, specialty, dateReceived, decisionDate, reviewDays, decision, submissionType, approvalStatement, supplementReason. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_fda_device_clearances.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
