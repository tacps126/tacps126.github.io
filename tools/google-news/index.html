Google News Scraper

Scrape Google News: search results, topic sections and top stories in any language and country — with the publisher's real article URL, publisher, date and related coverage. Site and time filters, new-article monitoring, instant API.

What to search for, one per line. Google News operators work: `"exact phrase"`, `-exclude`, `OR`, `intitle:word`.

Topic sections to include, as shown on Google News. Can be combined with search queries.

Limit searches to these publishers' domains, e.g. `reuters.com`, `bbc.co.uk`. With no search query, returns everything recent from these sites.

Exclude these publishers' domains from searches, e.g. `example-tabloid.com`.

Skip articles whose headline contains any of these words (case-insensitive), e.g. `stock`, `opinion`.

Only articles published in this window (applies to searches).

Only articles published on or after this date. Use instead of “Published within” for a fixed period.

Only articles published before this date.

Edition language as a 2-letter code, e.g. `en`, `de`, `fr`, `es`, `hi`, `ja`.

Edition country as a 2-letter code, e.g. `US`, `GB`, `IN`, `DE`, `AU`.

Return each article's real URL on the publisher's site instead of a Google News redirect link. Recommended.

Add other outlets' coverage of the same story (topic and top-story feeds).

Maximum number of articles to return in total.

Optional cap per search or topic (Google News shows up to about 100 each).

Monitoring

Return only articles that no earlier run with the same input has delivered. Ideal for news alerts — you pay only for new articles.
