Guide

How Sanctions Screener works

Inputs, options and tips, from the tool's own documentation.

Screen people and companies against the official sanctions lists, read straight from each publisher: the US OFAC SDN and consolidated (non-SDN) lists, the UN Security Council consolidated list, the EU consolidated financial sanctions list, the UK Sanctions List, Canada's consolidated autonomous sanctions list and the Swiss SECO list. About 46,000 listed people, organisations, vessels and aircraft, refreshed on every run.

Built for KYC and KYB onboarding, fintechs and payment companies, trade and logistics compliance, vendor and partner due diligence, procurement, and AI agents that need a sanctions check.

Matching that copes with real names

  • Transliteration. Владимир Путин, PUTIN, Vladimir and Vladimir Putin are the same name; so are Mohammed and Muhammad, Gaddafi and Qaddafi.
  • Any word order, patronymics and initials. V. Putin and Vladimir Vladimirovich PUTIN are found too.
  • Company forms ignored. Ltd, LLC, PJSC, OOO, GmbH… don't count. Generic words such as Bank, Trading or Group count for less, so Bank alone doesn't match every listed bank.
  • Fewer false positives. Add a date of birth or a country: a different birth year or country lowers a match and is flagged under checks. A strong name match is never hidden, only lowered.

Three modes

  1. Screen names. Paste names (one per line), or send subjects with your own reference, date of birth, country and type.
  2. Follow changes. Schedule mode changes (daily, for example). Each run reports the new designations and the removals since the last run, optionally only for some programmes or countries. The first run saves a baseline.
  3. Export. All entries, or only those matching programmes (RUSSIA, IRAN, SDGT…), countries, entity type, or a listing date, in one schema.

Real-time API

Run it in Standby mode for screening during onboarding: the lists are read once and kept in memory for six hours, so each call answers in milliseconds:

Questions

Questions about Sanctions Screener

How much does Sanctions Screener cost?

$3 per 1,000, charged only for name screeneds returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Sanctions Screener return?

Every row has the same fields, including status, topScore, matches[].matchedName, matches[].list, listName, matches[].programs, matches[].countries, birthDates, identifiers, matches[].checks, matches[].url. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as screen_sanctions.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
