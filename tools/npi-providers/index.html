Guide

How NPI Registry Scraper works

Inputs, options and tips, from the tool's own documentation.

US healthcare providers from the official NPI Registry (CMS NPPES): doctors, dentists, nurse practitioners, therapists, pharmacists, clinics, practices and hospitals. Each provider comes with specialty, license number and state, practice address, phone and fax, mailing address, and for organizations the authorized official (name, title, phone). Search by specialty, state, city, ZIP code, name or NPI; get new practices as they register.

Built for healthcare B2B sales (dental and medical supplies, software, pharma), medical staffing and recruiting, healthcare marketing agencies, insurers and provider networks, and AI agents.

Why this Actor

  • Official source, every US provider with an NPI (about 9 million records).
  • Complete lists: combine specialties with states and cities or ZIP codes; the Actor runs every combination.
  • New practices: New in the last N days + Only new providers on a schedule.
  • For AI agents. Callable as an MCP tool.

How to use it

Dental practices in Austin and Dallas:

json
{ "specialties": ["Dentist"], "states": ["TX"], "cities": ["Austin", "Dallas"], "providerType": "organization" }

New chiropractors in Florida each week:

json
{ "specialties": ["Chiropractor"], "states": ["FL"], "cities": ["Miami", "Orlando", "Tampa"], "enumeratedWithinDays": 30, "onlyNew": true }

Pricing

$3 per 1,000 providers plus a small start fee per run. On the Apify free plan a run returns up to 100 providers.

Good to know

  • The registry answers about 1,200 results per search: add cities or ZIP codes to get everyone in a big state (the run says when a search hit the limit).
  • Data is as providers report it to CMS. Questions: tacps126@gmail.com.
Questions

Questions about NPI Registry Scraper

How much does NPI Registry Scraper cost?

$3 per 1,000, charged only for providers returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does NPI Registry Scraper return?

Every row has the same fields, including npi, type, name, credential, gender, status, enumerationDate, lastUpdated, specialty, taxonomyCode, licenseNumber, licenseState, taxonomies, street, city, state, zip, phone, fax, mailingAddress, authorizedOfficial (name, title, credential, phone), otherNames, directAddresses, url. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_healthcare_providers.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
