Every creator gets a 0 to 100 score for how well they fit for a brand deal or collaboration: 1k-100k followers, engagement, recent posts, e-mail, other platforms. Keep only profiles at or above this score.

Guide

How Creator Finder works

Inputs, options and tips, from the tool's own documentation.

Find creators for brand deals, sponsorships and collaborations on YouTube, Instagram, TikTok and Vimeo in one table: followers, average views, likes and comments, engagement rate, latest post date, country, bio, e-mails and socials, verified badge and a lead score, plus their latest videos and posts with views, likes and comments. Search a topic on YouTube and Vimeo, or paste channel and profile links from any of the four. Filter by size, engagement, recency, country and contact details.

Built for brands and influencer agencies, creator and UGC marketers, sponsorship and partnership teams, talent managers and MCNs, researchers, and AI agents.

How to use it

Micro creators for a topic on YouTube, 1,000 to 100,000 subscribers, at least 2% engagement, with an e-mail:

json
{ "searchTerms": ["home barista", "latte art"], "platforms": ["youtube"], "profilesPerSearch": 50, "minFollowers": 1000, "maxFollowers": 100000, "minEngagementRate": 2, "mustHave": ["email"], "itemsPerProfile": 0 }

A shortlist of creators across sites, with their latest 3 videos or posts:

json
{ "startUrls": ["https://www.youtube.com/@LofiGirl", "https://www.instagram.com/lofigirl/", "https://www.tiktok.com/@lofigirl"] }

YouTube creators plus the Instagram and TikTok accounts they link to:

json
{ "searchTerms": ["street photography"], "platforms": ["youtube"], "socialStats": ["instagram", "tiktok"], "itemsPerProfile": 0 }

New creators for a topic, every week (schedule it):

json
{ "searchTerms": ["ai tools review"], "platforms": ["youtube"], "onlyNew": true, "itemsPerProfile": 0 }

Questions

Questions about Creator Finder

Can it search Instagram and TikTok?

Not by keyword: paste their profile links, or search YouTube and turn on Instagram and TikTok stats to read the accounts creators link to.

What is the lead score?

A 0 to 100 score for how well a creator fits for a brand deal or collaboration: 1k to 100k followers (+25; 100k to 1M +15), engagement of 3% or more (+20; 1 to 3% +10), a post in the last 30 days (+20; 90 days +10), an e-mail address (+20), accounts on two or more other platforms (+15). Results from each link or search are sorted by it, highest first.

How is engagement worked out?

From the latest videos or posts (at least 3, or all on one TikTok page): (average likes + average comments) divided by average views on YouTube and Vimeo, or by followers on Instagram and TikTok, in percent. TikTok lists views only on its latest videos, so likes there are the account's lifetime likes per video.

Is this legal?

It reads public profile and catalogue pages anyone can open without an account. Use the data in line with the platform's terms and privacy law where you are, especially for e-mail outreach.

Do I need an account, API key or cookies?

No.

Why is a value empty?

Each platform shows different numbers, and some profiles leave fields blank. Missing values are null, so columns always line up.

Free plan?

Free-plan runs are limited to a small number of results per month. Paid plans have no limit.

How much does Creator Finder cost?

$2 per 1,000, charged only for profiles returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Creator Finder return?

Every row has the same fields, including platform, id, url, username, name, verified, private, followers, following, videoCount, postsCount, totalViews, likesCount, avgViews, avgLikes, avgComments, engagementRate, latestRelease, isBusiness, businessCategory, country, bio, avatarUrl, headerImageUrl, createdAt. Download as JSON, CSV, Excel or XML.
