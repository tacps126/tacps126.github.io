ImmobilienScout24 Scraper

Scrape ImmobilienScout24 apartments and houses for rent or sale in Germany and Austria: price, warm rent, m², rooms, price per m², address with GPS, energy class, features, agent, photos and dates. Fast, filters, new-listing alerts.

Build the input, get the call

Change any field; the code on the right follows. Copy it, or run the same input on Apify.

Which ImmoScout24 site to search.

Cities, districts or regions in plain words, one per line. Germany: `Berlin`, `München Schwabing`, `Köln`. Austria: a city or federal state, e.g. `Wien`, `Graz`, `Tirol`.

What kind of property.

Listings for rent or for sale.

Or paste ImmoScout24 search result pages (.de or .at) from your browser, with any filters you set there. Each is crawled as given.

Limits

Result pages to read for each location or search URL (about 20 listings per page, more when new-build projects group their units).

Monitoring

Return only listings that no earlier run with the same input has delivered. Ideal for alerts — you pay only for new listings.
