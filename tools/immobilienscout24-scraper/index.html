Guide

How ImmobilienScout24 Scraper works

Inputs, options and tips, from the tool's own documentation.

Get property listings from ImmobilienScout24 (ImmoScout24), Germany's largest real-estate portal, and its Austrian site immobilienscout24.at, as a clean, spreadsheet-ready dataset. Apartments and houses for rent or sale anywhere in Germany and Austria. Each listing includes the price or cold rent, total (warm) rent, living area, rooms, price per m², full address with GPS coordinates, energy class, construction year, features (balcony, lift, fitted kitchen, cellar, garden...), agent or private landlord, photos and publish/update dates. Export to JSON, CSV or Excel, send to Google Sheets, or call it as an API.

Built for property investors and buy-to-let analysts, estate agents and property managers watching the market, relocation services, proptech and rental-price research, and anyone who wants new listings the moment they appear.

Why this scraper

  • Fast. In our tests, 1,100+ listings came back in about 20 seconds. After the first page loads, results are read directly instead of opening a browser for every page.
  • Germany and Austria. Pick the country: Berlin, München Schwabing, Köln in Germany, or Wien, Graz, Salzburg, Tirol in Austria.
  • Plain-word locations. Type Berlin, München Schwabing or Köln. The Actor finds the right ImmoScout24 area for you. Or paste any ImmoScout24 search URL with the filters you set on the site.
  • Analysis-ready fields. Price per m² is computed for you, warm rent sits next to cold rent, features come as simple English names, and coordinates are included whenever the listing shows its address.
  • Filters. Price, living area and rooms, newest first, and private landlords vs. agents. Skipped listings are never charged.
  • New-listing alerts. Schedule it with Only new listings and each run returns only listings you haven't received yet, so you pay only for new ones.
  • Price-change tracking. Turn on Changes only and schedule it: each run returns only listings that are new, whose price, rent, size, rooms or title changed (with the old and new values, e.g. "changes": {"price.amount": {"old": 1450, "new": 1395}}), or that were taken down (changeType: "removed"). Unchanged listings are skipped and not charged. Each changed listing also carries priceHistory (dated prices across runs).
  • Price-cut feed. Turn on Price drops only and schedule it daily: you get only listings whose price went down, with old and new price and the history.
  • Resilient. When ImmoScout24 shows its robot check, the Actor gets past it on a fresh connection automatically. Results are saved as each search finishes, and a moved run resumes without charging twice.

How to use it

  1. Pick the Country (Germany or Austria) and add Locations (e.g. Berlin, Hamburg Altona, Wien) and choose Property type (apartment or house) and Rent or buy.
  2. Optionally set price, area and rooms filters and Sort by: Newest first.
  3. Press Start. Download results from the Output tab, or connect an integration.

Questions

Questions about ImmobilienScout24 Scraper

How many listings can I get?

As many as the search has. Raise Max pages per search (about 20 listings per page, more when new-build projects list several units).

Does it cover Austria and Switzerland?

Austria yes (immobilienscout24.at: set Country to Austria; use a city or federal state as location). Switzerland (immoscout24.ch) isn't supported.

Why do some listings have no coordinates?

Some landlords hide the exact address until you contact them; those listings come with postcode, city and district only.

Is it legal?

The Actor collects publicly listed property ads. You're responsible for how you use the data, including contact names, under GDPR and the other laws that apply to you.

How much does ImmobilienScout24 Scraper cost?

$1 per 1,000, charged only for listings returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does ImmobilienScout24 Scraper return?

Every row has the same fields, including title, url, id, portal, offerType, propertyType, price, totalRent, livingArea, plotArea, rooms, pricePerSqm, address, latitude, longitude. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_german_property_listings.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
