One or more leagues. Box scores, teams and rosters cover team sports; standings also cover F1 (drivers, constructors) and ATP/WTA (singles rankings).

Games give scores, status, venue, TV, team records, leaders, key events (goals, cards) and odds where shown. Odds give opening and current (closing after the game) moneyline, spread and total per sportsbook, fair win probability, line…

Dates (games and box scores)

1 = yesterday and today.

Upcoming fixtures, e.g. 7 for the next week's schedule.

YYYY-MM-DD; replaces Days back.

YYYY-MM-DD; replaces Days ahead. Up to about one season per run.

Box scores always use finished games.

Filters

Team or player names or abbreviations, e.g. Lakers, KC, Arsenal, Sinner. Empty = all.

Tennis matches only: singles, doubles or both.

The season's year as ESPN numbers it, e.g. 2026 for the 2025-26 NBA season. Empty = current.

Most rows returned per run.

Monitoring

Schedule the Actor and each run returns only what earlier runs did not deliver. A game comes again when its status changes (scheduled, live, final), so a daily run with Game status = Final gives each result once.
