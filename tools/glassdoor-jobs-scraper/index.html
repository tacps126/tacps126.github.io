Guide

How Glassdoor Jobs Scraper works

Inputs, options and tips, from the tool's own documentation.

Get job listings from Glassdoor by keyword and location as a clean, spreadsheet-ready dataset. Each job includes the title, company, location, salary range (10th-90th percentile) with the median and the yearly equivalent, whether the pay is employer-provided or a Glassdoor estimate, job type, work mode, benefits, the skills tagged on the posting, the company's Glassdoor rating and logo, and the link to the job. Export to JSON, CSV or Excel, send to Google Sheets or Slack, or call it as an API.

Built for recruiters and staffing agencies, job boards and aggregators, compensation and HR analysts benchmarking pay, sales teams looking for companies that are hiring, and job seekers who want new postings delivered to them.

Why this scraper

  • Pay data included. Glassdoor shows a pay range for most jobs. You get it as min/max/median with currency, period and yearly equivalent, plus a flag for employer-provided vs. estimated pay.
  • Rich, standardized records. Work mode, employment type, seniority and job function are filled in the same way as in our other job scrapers (Indeed, LinkedIn, Greenhouse, Lever, Workday...), so you can combine sources in one table.
  • Any location. Type a city, state or country in plain words (Chicago, IL, London, Germany). The Actor finds the matching Glassdoor location for you.
  • Wide search for more jobs. Turn on Wide search and each query + location is searched from several angles (most relevant, newest, last 24 hours, last 3 days, full-time, contract, part-time) to collect several times more distinct jobs.
  • New-job monitoring. Schedule it with Only new jobs and each run returns only postings you haven't received yet, so you pay only for new ones.
  • Changes only. Turn on Changes only and schedule it: each run returns only new jobs and jobs whose salary, location or title changed (with old and new values). Unchanged jobs are skipped and not charged.
  • Filters applied for you. Title keywords, work mode, employment type, seniority, job function, minimum salary, "with salary only", excluded companies. Filtered-out jobs are never charged.
  • No account needed. Nothing to log in to.
  • Resilient. If Glassdoor shows a security check, the search is retried automatically on a fresh connection. Results are saved as each search finishes, and a moved run resumes without charging twice.

How to use it

  1. Add Search queries (e.g. registered nurse, data analyst) and Locations (e.g. Chicago, IL).
  2. Optionally pick Posted within, Job type and Sort by, and turn on Wide search for more results.
  3. Press Start. Download results from the Output tab, or connect an integration.

How many jobs per search?

Each search pages through Glassdoor's results (30 per page) until it has its share of Max results - up to about 900 jobs per search. For even more, add locations or related queries, turn on Wide search, or schedule the Actor with Only new jobs to build up a complete feed over time. Full job descriptions aren't included; you get the summary shown in search results plus the tagged skills and benefits.

Pricing

Pay per result: about $0.95 per 1,000 jobs (lower on higher Apify plans) plus a tiny start fee; price returns to $3 per 1,000 on ~6 December 2026. Duplicates, filtered-out jobs and (with Only new jobs) already-delivered jobs are free. See the Pricing tab for exact rates, and set a maximum charge per run to cap spend.

Questions

Questions about Glassdoor Jobs Scraper

Why do some searches take longer?

Every search opens Glassdoor in a real browser. When Glassdoor shows a security check, the search is retried on a fresh connection.

Is it legal?

The Actor collects publicly listed job ads. You're responsible for how you use the data, including any personal data, under the laws that apply to you.

How much does Glassdoor Jobs Scraper cost?

$0.95 per 1,000, charged only for jobs returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Glassdoor Jobs Scraper return?

Every row has the same fields, including title / company, location, city, region, countryCode, salary, salaryMedian, salaryIsEstimate, workMode, employmentType, jobTypes, benefits, skills. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
