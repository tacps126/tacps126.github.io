Guide

How Naukri Jobs Scraper works

Inputs, options and tips, from the tool's own documentation.

Get job listings from Naukri.com, India's largest job board, by keyword and city as a clean, spreadsheet-ready dataset. Each job includes the title, company, the company's AmbitionBox rating and review count, the experience range in years, the city, the skills tagged on the posting, and the link to the job. With Full job details on (the default) you also get the full description, the salary as a rupee min/max per year when the employer shows it, the industry, department, qualifications and closing date. Export to JSON, CSV or Excel, send to Google Sheets or Slack, or call it as an API.

Built for recruiters and staffing agencies hiring in India, HR and compensation analysts, job boards and aggregators, sales teams looking for companies that are hiring, and job seekers who want new postings delivered to them.

Why this scraper

  • Full job details. Not just the search card: the complete description, salary, industry, department, education required and the date the posting closes, read from each job's own page.
  • Salary in numbers. Naukri shows pay as text like 8-18 Lacs PA. You get it as {min: 800000, max: 1800000, currency: "INR", period: "year"} as well, ready to sort and filter.
  • Experience in numbers. 2-5 Yrs becomes yearsExperienceMin: 2, yearsExperienceMax: 5.
  • Rich, standardized records. Employment type, seniority, job function and work mode are filled in the same way as in our other job scrapers (Indeed, Glassdoor, LinkedIn, Greenhouse, Lever, Workday...), so you can combine sources in one table. The text Naukri shows is kept next to each normalized value (employmentTypeRaw, experienceLevelRaw, salaryText).
  • Many pages per search. Up to 500 jobs per query and city (20 per results page).
  • New-job monitoring. Schedule it with Only new jobs and each run returns only postings you haven't received yet, so you pay only for new ones.
  • Changes only. Turn on Changes only and schedule it: each run returns only new jobs and jobs whose salary, location or title changed (with old and new values). Unchanged jobs are skipped and not charged.
  • Filters applied for you. Title keywords, employment type, seniority, job function, minimum salary, "with salary only", excluded companies. Filtered-out jobs are never charged.
  • No account needed. Nothing to log in to; the Actor reads the same pages any visitor sees.
  • Resilient. If a search page doesn't load, it is retried automatically on a fresh connection. Results are saved as each search finishes, and a moved run resumes without charging twice.

How to use it

  1. Add Search queries (e.g. python developer, data analyst, sales manager) and Locations (e.g. Bangalore, Pune, Delhi NCR).
  2. Optionally pick Posted within and set Max jobs.
  3. Press Start. Download results from the Output tab, or connect an integration.

Pricing

Pay per result: about $1.50 per 1,000 jobs with full details (lower on higher Apify plans) plus a tiny start fee. See the Pricing tab for exact rates, and set a maximum charge per run to cap spend. Duplicates, filtered-out jobs and (with Only new jobs) already-delivered jobs are free.

On Apify's free plan each run returns up to 100 jobs, enough to try it out. Any paid Apify plan removes the limit.

Questions

Questions about Naukri Jobs Scraper

Why do runs take a minute or two?

Naukri builds its pages in the browser, so every search opens Naukri in a real browser, and with Full job details on each job's page is opened too. Turn details off for a faster run with the search-card data only.

Why are some salaries empty?

Many employers on Naukri choose "Not disclosed". Turn on Only jobs with salary to keep only jobs that show pay.

Is it legal?

The Actor collects publicly listed job ads. You're responsible for how you use the data, including any personal data, under the laws that apply to you.

How much does Naukri Jobs Scraper cost?

$1.50 per 1,000, charged only for jobs returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Naukri Jobs Scraper return?

Every row has the same fields, including title / company, companyRating, companyReviewCount, ambitionBoxUrl, companyId, companyUrl, companyLogo, location, city, countryCode, experienceLevelRaw, yearsExperienceMin, yearsExperienceMax, salary, salaryText, skills, description, summary, industry, department, qualifications. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_naukri_jobs.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
