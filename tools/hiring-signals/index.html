Hiring Signals & Buying Intent Data from Job Postings

Buying-intent signals for sales teams: see which target companies are hiring for the roles you sell to, how many roles, how fresh, and what's new since last week. Scored per company, from career pages and job searches. Schedule it for a weekly intent feed.

Change any field; the code on the right follows. Copy it, or run the same input on Apify.

Your target accounts' jobs pages — Greenhouse, Lever, Ashby, Workday, SmartRecruiters, Recruitee, Personio or Teamtailor links. Every open role is read.

Find companies you don't know yet: job searches like `data engineer` or `head of security`. Every company hiring for it becomes a signal.

Where to search, e.g. `Germany`, `London`, `United States`.

Signal criteria

A role counts when its title contains any of these words — the teams that buy what you sell (e.g. `security`, `data engineer`, `revops`). Leave empty to count every open role.

Roles whose title contains any of these never count, e.g. `intern`, `working student`.

Only roles whose location contains any of these, e.g. `Germany`, `Remote`, `New York`.

Only roles posted in the last N days count (roles without a date always count). 0 = any age.

Keep only these seniority levels.

Keep only these job functions (engineering, data, sales, …).

Keep only these work arrangements. Jobs whose posting doesn't state it are dropped when this is set.

Keep only these employment types.

Count a role only if its description or skills mention any of these, e.g. `Snowflake`, `Kubernetes` — great for tech-stack signals.

Never report companies whose name contains any of these (e.g. existing customers, recruiters).

Report a company only when at least this many roles match.

Include each company's matching roles (title, link, location, seniority, date) in its record.

Maximum number of company signals to return (highest score first).

How many result pages to read per discovery search (about 10 jobs each).

Monitoring

Report a company only the first time it shows a signal, or when it opens new matching roles since the last run with the same input. You pay only for changes.

FieldWhat it holds
company / companySlug / companyLogoCompany name, its career-page handle, and logo when available
signalScore0–100: volume of matching roles (up to 50) + roles posted in the last 7 days (up to 30) + new roles since last run (20)
matchingRoles / newMatchingRolesRoles matching your criteria, and how many are new since the last run
rolesPostedLast7DaysMatching roles opened in the past week
totalOpenRoles / openRolesChangeAll open roles at the company, and the change since the last run
functions / seniority / topLocationsBreakdown of the matching roles (e.g. {"data": 6, "engineering": 4})
matchedKeywordsWhich of your keywords matched, and how often
remoteShareShare of matching roles that are remote (%)
newestRolePostedAt / firstSeenAtNewest matching role, and when the company first showed a signal
rolesThe matching roles (new ones first): title, link, location, seniority, function, work mode, posting date
board / scrapedAtWhere the roles came from, and when
