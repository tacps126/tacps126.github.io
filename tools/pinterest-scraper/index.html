Guide

How Pinterest Scraper works

Inputs, options and tips, from the tool's own documentation.

Get Pinterest pins, profiles and boards as clean rows: image and video links, title, description, the outbound link and its site, saves, comments and reactions, product name and price, pinner and board, and when the pin was created. Search by keyword or paste profile, board and pin links. No login, no cookies, nothing to install.

How to use

  1. Add search terms (modern kitchen) and/or links under Profiles, boards and pin links: a username or profile link returns the profile and the pins it created, a board link returns the board and its pins, a pin link returns that pin.
  2. Choose how many pins per search, profile and board.
  3. Press Start. Download the results as JSON, CSV or Excel, or send them to a webhook or Google Sheets.

Example input

json
{
  "searchTerms": ["modern kitchen"],
  "startUrls": [
    "https://www.pinterest.com/nasa/",
    "https://www.pinterest.com/pin/142567144449081155/"
  ],
  "maxPinsPerSource": 50,
  "includeBoards": true
}

Monitoring

Turn on Only new pins and schedule the Actor: each run returns only pins that earlier runs did not deliver, while profiles and boards come back every run so you can track followers over time.

Good to know

  • Only public data is read.
  • Pins from search results and from the "saved from others" part of a board have no Pinterest page link of their own; their image, outbound link, pinner and board are still included.
  • Comment texts are not included; pins carry their comment count.
Questions

Questions about Pinterest Scraper

Do I need a Pinterest account?

No.

How fast is it?

About 150 rows in under 10 seconds.

How much does Pinterest Scraper cost?

$1.50 per 1,000, charged only for pins returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Pinterest Scraper return?

Every row has the same fields, including Pin, Pin from search, Profile, Board. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_pinterest_pins.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
