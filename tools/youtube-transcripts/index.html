Guide

How YouTube Transcript Scraper works

Inputs, options and tips, from the tool's own documentation.

Get the full transcript of any YouTube video - and of every video in a playlist, a channel or a search - as clean text with timestamps, plus the video's title, channel, publish date, length, views, description and keywords.

Built for AI and RAG pipelines, content repurposing (blogs, newsletters, shorts), research and media monitoring, SEO and keyword analysis, accessibility, and developers who need captions without an API key.

At a glance

  • Price: $2.50 per 1,000 transcripts; videos without captions are free. Free plan: up to 100 transcripts per run.
  • First run: the prefilled video comes back in about a second: 487 words in 61 timed segments, with title, channel, length, views and caption language.

How to use it

json
{
  "videos": [
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
    "https://www.youtube.com/@Fireship",
    "https://www.youtube.com/playlist?list=PLrAXtmErZgOeiKm4sgNOknGvNjby9efdf"
  ],
  "searchQueries": ["rust async tutorial"],
  "maxVideosPerSource": 10,
  "languages": ["en"]
}
  • Videos, playlists, channels, searches. Paste any mix: links, bare video ids, @handles, channel links, playlist links. Channels give the newest videos first.
  • Your language. Give languages in order of preference; a written transcript beats an auto-generated one. Set translateTo to ask for a machine translation; this is best effort: when YouTube refuses, the original language is returned with a translationNote.
  • Plain text or timestamps. includeSegments adds every caption line with its start time; turn it off for smaller output.
  • Follow new uploads. Turn on Only new videos and schedule the Actor: each run returns only videos earlier runs haven't delivered, so you pay only for new transcripts.

Pricing

$2.50 per 1,000 transcripts plus a small start fee per run. Videos without captions (or private or removed ones) are listed in the run summary and are not charged.

Free-plan runs return up to 100 transcripts per run.

Good to know

  • Videos need captions: a written track from the uploader, or YouTube's auto-generated captions. Videos with captions switched off, private, removed or age-restricted ones are reported and skipped.
  • The Actor also runs in Standby mode - an always-ready endpoint that returns transcripts in the response, handy for apps and AI agents. Find the URL on the Standby tab.

Questions

Questions about YouTube Transcript Scraper

Does it need a YouTube API key?

No.

Can I get only the text?

Yes: turn off Include timestamps and Include video details; transcript still holds the text.

Why is a video missing?

It has no captions, or it is private, removed or restricted. The run summary says which and why.

How much does YouTube Transcript Scraper cost?

$2.50 per 1,000, charged only for transcripts returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does YouTube Transcript Scraper return?

Every row has the same fields, including videoId, url, title, channel, channelId, channelUrl, publishedAt, lengthSeconds, views, transcript, segments, language, captionLanguage, isAutoGenerated, availableLanguages, wordCount, description, keywords. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_youtube_transcripts.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
