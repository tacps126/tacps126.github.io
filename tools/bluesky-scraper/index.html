Guide

How Bluesky Scraper works

Inputs, options and tips, from the tool's own documentation.

Bluesky posts by keyword with likes, reposts, replies, quotes, hashtags, mentions, links and images; profiles with bio, follower counts, links and emails from the bio, plus their latest posts; followers lists; and full threads with replies. Filter by date, language, author, linked domain and engagement, and schedule it as a brand or topic monitor that returns only new posts.

Built for social listening and brand monitoring teams, researchers, marketers and growth teams, and AI agents.

Why this Actor

  • Search, profiles, followers and threads in one run, one clean row shape.
  • Filters that matter: last N days or a date range, language, one author, posts linking to a domain, minimum likes or reposts, no replies, no reposts.
  • Monitoring built in: turn on Only new results and schedule it; each run returns only posts it has not delivered before.
  • Lead research: emails and links from bios of profiles and followers.
  • For AI agents. Callable as an MCP tool.

How to use it

Monitor mentions of a brand, newest first:

json
{ "searchTerms": ["apify", "\"web scraping\""], "postedWithinDays": 7, "language": "en", "onlyNew": true }

A profile, its last 50 posts and 500 followers:

json
{ "profiles": ["bsky.app"], "maxPostsPerProfile": 50, "maxFollowersPerProfile": 500 }

Search returns up to 100 posts per search term. For more, add your own Bluesky handle and an app password (Bluesky Settings > Privacy and security > App passwords). It is used only to read search results; nothing is posted.

Questions

Questions about Bluesky Scraper

How much does Bluesky Scraper cost?

$0.70 per 1,000, charged only for results returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Bluesky Scraper return?

Every row has the same fields, including text, createdAt, url, languages, authorHandle, authorName, authorUrl, authorAvatar, likeCount, repostCount, replyCount, quoteCount, hashtags, mentions, links, images, videoUrl, linkCard, quotedPostUrl, isReply, replyToUrl, threadRootUrl, Profiles and followers: handle, displayName, description, followersCount, followsCount, postsCount, emails, links, verified, createdAt, type, source, scrapedAt. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
