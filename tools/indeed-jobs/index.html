Guide

How Indeed Jobs Scraper works

Inputs, options and tips, from the tool's own documentation.

Get job listings from Indeed by keyword and location in 9 countries as a clean, spreadsheet-ready dataset. Each job includes the title, company, location (city, state, postcode, country), the full job description (no Indeed login needed), salary range with the yearly equivalent, job type, work mode (remote / hybrid), benefits, schedule, the skills Indeed tagged, the company's rating and the link to the job. Export to JSON, CSV or Excel, send to Google Sheets or Slack, or call it as an API.

Built for recruiters and staffing agencies sourcing openings, job boards and aggregators, sales teams looking for companies that are hiring, analysts tracking salaries and demand, and job seekers who want new postings delivered to them.

Why this scraper

  • Full descriptions without a login. Turn on Full descriptions and each job comes with its complete description, the way Indeed's own job panel shows it - most Indeed scrapers return only the search snippet or ask for your cookies.
  • Rich, standardized records. Salaries are parsed into min/max/currency/period with a yearly equivalent. Work mode, employment type, seniority and job function are filled in the same way as in our other job scrapers (Greenhouse, Lever, Workday, LinkedIn...), so you can combine sources in one table.
  • Wide search for more jobs. Turn on Wide search and each query + location is searched from several angles (newest, most relevant, last 24 hours, last 3 days, full-time, contract, part-time). In our tests that gave about 3× more distinct jobs for the same search.
  • 9 country sites. United States, United Kingdom, Canada, Australia, Ireland, Germany, France, Netherlands and Singapore.
  • New-job monitoring. Schedule it with Only new jobs and each run returns only postings you haven't received yet, so you pay only for new ones.
  • Changes only. Turn on Changes only and schedule it: each run returns only new jobs and jobs whose salary, location or title changed (with old and new values). Unchanged jobs are skipped and not charged.
  • Filters applied for you. Title keywords, location, work mode, employment type, seniority, job function, minimum salary, "with salary only", excluded companies. Filtered-out jobs are never charged.
  • No account needed. Nothing to log in to, nothing to configure beyond your search.
  • Resilient. If Indeed shows a security check, the search is retried on a fresh connection - but only when that has been working, so a blocked day doesn't burn your budget. Results are saved as each search finishes, and a moved run resumes without charging twice.

How to use it

  1. Add Search queries (e.g. registered nurse, data analyst) and Locations (e.g. Chicago, IL, Remote).
  2. Pick the Indeed country site and, optionally, Posted within, Job type and Sort by.
  3. For more results per search, turn on Wide search.
  4. Press Start. Download results from the Output tab, or connect an integration.

Using your own sign-in (optional)

You do not need this. A normal run needs no account: it reads the first results page of every search, and with Full descriptions on, every job's description. Paste your own sign-in only if you want more result pages per search (set Pages per search).

Copy it in two minutes (Chrome, Edge or Firefox):

  1. Sign in to Indeed in your browser.
  2. Press F12 (Mac: Cmd+Option+I) and open the Network tab.
  3. Reload the page (F5) and click the first request in the list.
  4. Right-click it and choose Copy > Copy as cURL (bash) (Firefox: Copy Value > Copy as cURL).
  5. Paste it into Your own Indeed sign-in and start the run.

On Safari, turn on Settings > Advanced > Show features for web developers, then use Develop > Show Web Inspector > Network and the same right-click menu.

Other shapes work too: the plain Cookie header (name=value; name2=value2), the JSON export of a cookie extension, or a cookies.txt file. Cookies for other websites in an export are left out automatically.

Good to know

  • It is a password. Use your own account, ideally a separate one. The field is stored encrypted, never appears in your results or logs, and signing out in your browser ends that session. We never ask for your password and never sign in for you.
  • Your account, your terms. Indeed's terms apply to your account, so use this the way you are comfortable with.
  • It expires. Sessions last days to weeks. When one has expired, the run says so before it spends anything: copy a fresh one.
  • Mistakes are explained, not silent. If what you pasted is a web address, empty, expired, or belongs to another site, the run stops at the start and tells you which, at no cost.

How many jobs per search?

Each search returns the jobs on Indeed's first results page: about 40 in the US and about 15 on the other country sites. For more jobs:

  • add more locations (nearby cities, suburbs or postcodes),
  • add related queries (RN, registered nurse, ICU nurse),
  • turn on Wide search (about 3× more distinct jobs per query + location),
  • schedule the Actor with Only new jobs to build up a complete feed over time.

Turn on Full descriptions to add each job's complete description (read from Indeed's own job panel, no login needed). Without it you get the summary Indeed shows in search results plus the tagged skills and benefits.

Questions

Questions about Indeed Jobs Scraper

Why do some searches take longer?

Every search opens Indeed in a real browser. When Indeed shows a security check, the search is retried on a fresh connection, which adds a few seconds.

Which countries are supported?

US, UK, Canada, Australia, Ireland, Germany, France, Netherlands and Singapore.

Is it legal?

The Actor collects publicly listed job ads. You're responsible for how you use the data, including any personal data, under the laws that apply to you.

How much does Indeed Jobs Scraper cost?

$1.50 per 1,000, charged only for jobs returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Indeed Jobs Scraper return?

Every row has the same fields, including title / company, location, city, region, postalCode, country, countryCode, workMode, employmentType, jobTypes, salary, salaryText, benefits, schedules, skills. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_indeed_jobs.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
