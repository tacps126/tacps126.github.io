Guide

How Events Scraper works

Inputs, options and tips, from the tool's own documentation.

Get upcoming events as a clean, spreadsheet-ready list: name, start and end time, venue with address and coordinates, organiser, hosts (with their public LinkedIn where the event lists it), ticket prices, free / sold-out, attendee count, image and full description. Search by topic and city, or paste links. Luma, Eventbrite and Meetup come back in one schema, so they combine into one table.

Built for: event marketers and sponsors scouting where their audience meets; sales and partnership teams prospecting organisers and hosts; community builders and agencies; researchers mapping an industry's event calendar. If you work trade shows, see also Trade Show Exhibitor List Scraper.

Why this scraper

  • Three sites, one format. The same fields for Luma, Eventbrite and Meetup, plus any website that publishes schema.org events (most event platforms do, for Google).
  • Search like a person. AI in London, startup in Bengaluru, crypto online, on all three sites. City names in plain words.
  • Or paste links:
  • a Luma city, category, organiser calendar or event;
  • an Eventbrite search or event;
  • a Meetup search or group;
  • any events page.
  • Organisers and hosts. Who runs each event, with their page; on Luma also the hosts.
  • Fast and light. A typical run takes seconds.
  • New-event alerts. Schedule it with Only new events: each run returns only events you haven't received yet, and you pay only for those.
  • Change alerts. Turn on Changes only and schedule it: each run returns only new events, events whose date, venue, status, price or sold-out state changed (old and new values in changes), and upcoming events that disappeared (changeType: "removed", cancelled or unlisted).

How to use it

  1. Type Topics or keywords (e.g. AI) and a Location (e.g. London, or online), or paste Event links.
  2. Choose Sites to search (Luma, Eventbrite, Meetup), or keep all three.
  3. Press Start. Download from the Output tab, or connect Google Sheets, Slack, Make, Zapier, n8n or webhooks.
json
{
  "searches": ["AI", "startup"],
  "location": "London",
  "maxItems": 100,
  "startUrls": [
    { "url": "https://luma.com/ai" },
    { "url": "https://www.meetup.com/find/?keywords=ai&location=us--ca--San%20Francisco&source=EVENTS" }
  ]
}

maxItems applies to each search on each site and to each link.

Meetup knows about 70 big cities by name; for other cities write City, CC with the two-letter country code (Lyon, FR), or paste a Meetup search or group link. Luma searches within a city; without a location, a keyword like ai, tech or crypto is used as a Luma category.

Pricing

Pay per result: about $1 per 1,000 events. Events filtered out as past or already delivered (Only new) are free. On Apify's free plan a run returns up to 200 events, enough to try it.

Use it in n8n, Make, Zapier or AI agents

Every run is one API call (run-sync-get-dataset-items). In n8n, use an HTTP Request node, or Apify's own node. AI agents can call it through Apify's hosted MCP server (https://mcp.apify.com?tools=tacps126/events-scraper).

Notes

  • Only public event pages are read. Hosts' names and LinkedIn links are shown as the organiser published them; use personal data within GDPR and the platforms' terms.
  • Sites that ask for a human check (captcha) are skipped and reported in the run log; this Actor does not solve captchas.
Questions

Questions about Events Scraper

How much does Events Scraper cost?

$1 per 1,000, charged only for events returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Events Scraper return?

Every row has the same fields, including name, url, source, startAt, endAt, timezone, isOnline, status, venue, organizer, hosts, price, attendeeCount. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as find_events.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
