Guide

How Instagram Scraper works

Inputs, options and tips, from the tool's own documentation.

Get Instagram profiles, posts, reels and comments as clean rows: followers, bio and links, likes and comment counts, captions with hashtags and mentions, exact post time, image and video links, carousel items, tagged users, location and audio. Paste usernames or post links and press Start. No login, no cookies, nothing to install.

How to use

  1. Add usernames (nasa, @natgeo) or profile links under Profiles, and/or post and reel links under Post and reel links.
  2. Choose how many latest posts per profile you want (up to 1,000) and how many comments per post.
  3. Press Start. Download the results as JSON, CSV or Excel, or send them to a webhook or Google Sheets.

Example input

json
{
  "profiles": ["nasa"],
  "postUrls": ["https://www.instagram.com/p/Dfc1mYxFevS/"],
  "postsPerProfile": 12,
  "commentsPerPost": 20
}

Monitoring

Turn on Only new posts and comments and schedule the Actor: each run returns only posts and comments that earlier runs did not deliver, while profiles come back every run so you can track follower counts over time.

Good to know

  • Only public data is read. Private accounts return their profile row only.
  • isPinned marks the posts pinned to the top of a profile, so they never push newer posts out of your results.
  • Usernames made only of digits (like 433) work.
  • View and play counts, comment replies and hashtag pages are not public, so they are not included.
  • Hashtag, location and search pages are not supported; use profiles and post links.
  • Image and video links from Instagram expire after a few days; download the files if you need to keep them.
Questions

Questions about Instagram Scraper

Do I need an Instagram account?

No.

How fast is it?

About 200 rows in 25 seconds for a profile with comments.

Can I get data for many profiles?

Yes, paste as many usernames as you like; set Max results to cap a run.

How much does Instagram Scraper cost?

$1.50 per 1,000, charged only for profiles returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Instagram Scraper return?

Every row has the same fields, including Profile, Post / reel, Comment. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
