Recruitee Jobs Scraper

Scrape all open jobs from any Recruitee career page — just type the company name. Fast, low-cost and clean: location, remote/hybrid, seniority, salary and skills in one consistent format. Monitor new jobs on a schedule.

Build the input, get the call

Change any field; the code on the right follows. Copy it, or run the same input on Apify.

Company names as they appear in the Recruitee jobs-page address — e.g. `bunq`.recruitee.com → `bunq` — or paste the career-page link itself.

Maximum number of jobs to return.

Optional cap per company, so one large employer can’t use up the whole “Max jobs”.

Filters

Keep a job only if its title contains any of these words (case-insensitive), e.g. `engineer`, `developer`.

Drop a job whose title contains any of these words (case-insensitive), e.g. `intern`, `manager`.

Keep a job only if its location contains any of these (case-insensitive), e.g. `Berlin`, `Remote`.

Keep only jobs posted in the last N days. Jobs whose board doesn't publish a date are kept.

Keep only jobs the posting itself marks as remote.

Keep only these work arrangements. Jobs whose posting doesn't state it are dropped when this is set.

Keep only these employment types.

Keep only these seniority levels.

Keep only these job functions (engineering, data, sales, …).

Keep a job only if its title, description or skills mention any of these, e.g. `Kubernetes`, `Python`, `SQL`.

Drop jobs from companies whose name contains any of these, e.g. staffing agencies.

Keep jobs paying at least this per year (hourly and monthly pay are converted), in the posting's currency. Jobs that don't publish pay are kept unless “Only jobs with salary” is on.

Keep only jobs that publish their pay.

Keep only jobs whose posting says visa sponsorship is available.

Monitoring

Return only jobs that no earlier run with the same input has delivered. Schedule the Actor and you pay only for new jobs.

Return only jobs that are new, changed or closed since the last run with the same input (or monitor name): changed jobs carry `changeType: "changed"` and `changes` with the old and new salary, location, title or work mode; jobs taken down…
