Guide

How Zillow Scraper works

Inputs, options and tips, from the tool's own documentation.

Get property listings from Zillow, the largest US real estate portal, as a clean, spreadsheet-ready dataset: homes for sale and rentals in any US city, county, ZIP code or neighborhood. Each listing includes the price (with monthly rent for rentals), bedrooms and bathrooms, square feet and price per square foot, full address with city, state and ZIP, GPS coordinates, the Zestimate and Rent Zestimate, tax assessed value, days on Zillow, price cuts with the amount and date, the listing broker and phone, open houses and photos. Apartment buildings come with their unit count and rent range. Export to JSON, CSV or Excel, send to Google Sheets, or call it as an API.

Built for real estate investors comparing asking prices with Zestimates, agents and brokers watching new and reduced listings, property managers tracking rents, proptech and analytics teams, and relocation services.

Why this scraper

  • Plain-word locations. Type Austin, TX, 60614, Lincoln Park, Chicago or Maricopa County, AZ. The Actor finds the matching Zillow area. Or paste any Zillow search URL with your filters.
  • Investor fields included. Zestimate, Rent Zestimate, tax assessed value, price per square foot and days on Zillow come with every listing, so you can screen deals without opening each page.
  • Price-cut tracking. Every listing says whether the price was cut (priceReduced), by how much (priceChange) and when (priceChangedAt).
  • Broker contact. Listing broker and phone number where Zillow shows them.
  • Filters. Rent or buy, apartments or houses, price range, bedrooms, newest first.
  • New-listing alerts. Schedule it with Only new listings and each run returns only listings you haven't received yet, so you pay only for new ones.
  • Price-change tracking. Turn on Changes only and schedule it: each run returns only listings that are new, whose price, rent, size, rooms or title changed (with the old and new values), or that were taken down (changeType: "removed"). Unchanged listings are skipped and not charged.
  • Price-cut feed. Turn on Price drops only and schedule it daily: you get only listings whose price went down, with old and new price and the history.

How to use it

  1. Add Locations (e.g. Austin, TX, 60614) and choose Rent or buy and Property type.
  2. Optionally set price and bedrooms filters and Sort by: Newest listed.
  3. Press Start. Download results from the Output tab, or connect an integration.

Questions

Questions about Zillow Scraper

How many listings can I get per search?

Zillow shows up to 20 pages (820 listings) per search. For more, split a big city into ZIP codes or neighborhoods, or into price bands.

Does it include the Zestimate?

Yes, the Zestimate for homes for sale and the Rent Zestimate where Zillow shows them.

Does it include the broker's phone number?

Where Zillow shows it on the listing card. Use it within the TCPA and other laws that apply to you.

Is it legal?

The Actor collects publicly listed property ads. You're responsible for how you use the data under the laws that apply to you.

How much does Zillow Scraper cost?

$1 per 1,000, charged only for listings returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Zillow Scraper return?

Every row has the same fields, including title, url, id, offerType, propertyType, listingKind, status, price, priceText, bedrooms, bathrooms, livingAreaSqft, livingArea, pricePerSqft, pricePerSqm, lotArea, address, latitude, longitude, zestimate, rentZestimate, taxAssessedValue. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
