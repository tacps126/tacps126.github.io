Guide

How Clinical Trials Scraper works

Inputs, options and tips, from the tool's own documentation.

Search ClinicalTrials.gov by condition, drug, device or sponsor and get every matching study as a clean row: official title, summary, status (recruiting, completed...), phase, conditions, interventions, sponsor, enrollment, start and completion dates, countries and investigators. Newest updates first. Schedule it with Only new results and it becomes an alert; follow it as an RSS/Atom feed; add AI summaries on your own AI key.

Built for pharma and biotech competitive-intelligence teams, CROs and site networks finding new studies, medical-affairs and BD teams, investors tracking pipelines, patient-recruitment agencies and AI agents.

At a glance

  • Price: $3 per 1,000 results, plus a small start fee per run.
  • First run: the prefilled search returns the newest results for "GLP-1 obesity" in seconds.
  • More sources in one run: Research Radar searches OpenAlex, arXiv, PubMed, Europe PMC, worldwide patents, ClinicalTrials.gov, DOAJ, DataCite and Crossref together and merges duplicates.

How to use it

  1. Enter one or more search queries, for example GLP-1 obesity, Alzheimer lecanemab, Pfizer RSV vaccine.
  2. Optionally set Published within (days) and Sort by.
  3. Press Start. Download from the Output tab, or connect Google Sheets, Slack, Make, Zapier, n8n or webhooks.

Each row carries the study's NCT id and link; Published within (days) keeps studies updated in that window, so a weekly schedule with Only new results catches new and changed trials.

{

    "Alzheimer lecanemab"

  "postedWithinDays": 30,
  "maxItems": 200

Pricing

$3 per 1,000 results (each paper or patent counts once, however many sources found it) plus a small start fee per run. Duplicates and, with Only new results, already-delivered items are free. AI summaries and translations cost the model's tokens: a fraction of a cent each with the built-in AI (billed to your Apify account by Apify's AI gateway), or your provider's price with your own key. See the Pricing tab, and set a maximum charge per run to cap spend.

Tips

  • Use several specific queries rather than one broad one; results are merged.
  • Queries match titles and abstracts, so papers that only mention your words in passing stay out.
  • For a literature review, set Sort by to Highest impact with Published within 1,100 days: the most influential work of the last three years, deduplicated, with BibTeX.
  • For a weekly alert, set Published within to 8 days and schedule weekly with Only new results.
  • A free OpenAlex key gives your runs their own daily budget.

Questions

Questions about Clinical Trials Scraper

How much does Clinical Trials Scraper cost?

$3 per 1,000, charged only for results returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Clinical Trials Scraper return?

Every row has the same fields, including type, title, abstract, authors, publishedAt, venue, doi, url, pdfUrl, openAccess, citations, language, keywords, citationsPerYear. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
