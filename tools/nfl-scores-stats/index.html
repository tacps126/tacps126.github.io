Guide

How NFL Scores, Box Scores & Stats works

Inputs, options and tips, from the tool's own documentation.

NFL scores and schedules, player box scores, standings with playoff seeds, teams and rosters with injury status, plus college football (all FBS teams). Pick dates or a whole season, filter by team, export to JSON, CSV or Excel, or schedule it to get each final once.

Built for fantasy and DFS players, bettors and prop modellers, football analysts and writers, newsletters and bots, and AI agents.

How to use it

This Sunday's results:

json
{ "leagues": ["nfl"], "daysBack": 2, "gameStatus": "final" }

Chiefs and Eagles player lines this season:

json
{ "leagues": ["nfl"], "dataType": "boxScores", "dateFrom": "2026-09-01", "teams": ["KC", "PHI"] }

College football this Saturday's schedule:

json
{ "leagues": ["ncaaf"], "daysBack": 0, "daysAhead": 3, "gameStatus": "scheduled" }

Opening and current betting lines for the next games:

json
{ "leagues": ["nfl"], "dataType": "odds", "daysBack": 0, "daysAhead": 3 }

Options

OptionWhat it does

Max results (maxItems)Most rows per run

Pricing

$3 per 1,000 games, odds rows, standings rows, teams or players, and $1 per 1,000 box-score player lines (an NFL game is about 80 lines, so about 8 cents), plus a small start fee per run. On the Apify free plan a run returns up to 100 rows.

Questions

Questions about NFL Scores, Box Scores & Stats

How much does NFL Scores, Box Scores & Stats cost?

$3 per 1,000, charged only for game, standing, team or players returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does NFL Scores, Box Scores & Stats return?

Every row has the same fields, including Games, Box scores, Odds, Standings, Teams / rosters. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
