Guide

How Website to Markdown Crawler works

Inputs, options and tips, from the tool's own documentation.

Turn any website or web search into clean Markdown for AI, RAG and LLM apps. Give it a site and it reads the pages it links to; give it a question and it reads the top search results. Each page comes back as Markdown of its main content, without menus, headers, footers, cookie banners or ads, plus its title, description, language, author, publish date and, if you want, every link. Export to JSON, CSV or Excel, load into a vector store, or call it as an API.

Built for AI developers feeding knowledge bases and RAG pipelines, agents that need fresh web context, teams moving docs or help centres into a chatbot, and anyone who wants pages as clean text.

Why this crawler

  • Main content only. Navigation, sidebars, footers and ads are dropped; headings, lists, tables, code blocks and links are kept.
  • Crawl or search, or both. Start addresses are crawled on the same site; searches read the top results with their rank and snippet.
  • Stays where you point it. Starting at /docs follows /docs/... pages only. Skip links by text (/tag/, ?page=).
  • No duplicates. The same page reached by two links, a trailing slash or index.html is read once.
  • Fast and cheap. Pages are read five at a time; a 50-page docs site takes seconds.
  • Ready for chunking. Word count on every row; skip thin pages with a minimum word count.

How to use it

  1. Add Websites to crawl (for example a docs site), Web searches, or both.
  2. Set Link depth and Max pages per website.
  3. Press Start. Download results from the Output tab, or connect an integration.
json
{
  "startUrls": ["https://docs.apify.com/academy"],
  "queries": ["how does retrieval augmented generation work"],
  "maxResultsPerQuery": 5,
  "maxPagesPerSite": 50,
  "maxDepth": 2
}

Questions

Questions about Website to Markdown Crawler

Does it read pages that need JavaScript?

It reads the page as the server sends it, which covers docs sites, blogs, news, help centres and most company sites. Pages that only draw their text with JavaScript come back thin; set a minimum word count to skip them.

Can I get the whole page instead of the main content?

Yes, turn on Whole page.

Does it follow links to other sites?

No, crawls stay on the start address's site. Search results can come from any site.

Can I keep a knowledge base fresh?

Yes. Schedule the run and send the dataset to your vector store or a webhook.

How much does Website to Markdown Crawler cost?

$1 per 1,000, charged only for pages returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Website to Markdown Crawler return?

Every row has the same fields, including url, title, wordCount, depth, query, rank, markdown. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_website_markdown.
