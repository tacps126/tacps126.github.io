For playlist or set links: their tracks, the profiles of the artists on them (up to 'Profiles per search term'), or both. New-music playlists are a good source of artists.

Guide

How Music Artist Scraper works

Inputs, options and tips, from the tool's own documentation.

Find and track music artists on SoundCloud and Spotify in one table: verified badge, independent or signed (from the label lines on their releases), label, followers, monthly listeners, top listener cities, similar artists, upcoming concerts, releases, playlists they were discovered on, e-mails and socials, and a lead score, plus their tracks with plays. Search by name or genre, paste artist links, or turn a playlist into a list of artists. Optional Instagram and TikTok stats for each artist.

Built for A&R scouts, labels and producers looking for artists, music marketers and playlist pitchers, booking agents and promoters, music-tech apps and researchers, and AI agents.

How to use it

Emerging independent artists like ones you already work with: similar artists, active in the last 3 months, on Instagram, with their Instagram stats:

json
{ "startUrls": ["https://open.spotify.com/artist/1eDIWVJt7ZWKsrXw5WVNsN", "https://soundcloud.com/lofi_girl"], "similarArtists": 20, "artistType": "independent", "releasedWithinDays": 90, "mustHave": ["instagram"], "socialStats": ["instagram"], "itemsPerProfile": 0 }

The artists on a new-music playlist, best leads first:

json
{ "startUrls": ["https://open.spotify.com/playlist/37i9dQZF1DXcBWIGoYBM5M"], "playlistMode": "artists", "profilesPerSearch": 50, "minLeadScore": 50, "itemsPerProfile": 0 }

Independent artists on SoundCloud and Spotify for a genre, between 1,000 and 50,000 followers:

json
{ "searchTerms": ["lofi"], "artistType": "independent", "minFollowers": 1000, "maxFollowers": 50000, "itemsPerProfile": 0 }

New artists for a search, every week (schedule it):

json
{ "searchTerms": ["afrobeats lagos"], "itemsPerProfile": 0, "onlyNew": true }

Questions

Questions about Music Artist Scraper

How is "independent" decided?

From the label lines on the artist's releases: the artist's own name or a self-release service means independent, a company name means signed. selfReleasedShare shows the mix. Artists who own their label, or who license their masters to a major under their own name, can show as independent. Use label to check.

What is the lead score?

A 0 to 100 score for how well a profile fits as an emerging independent artist to sign, promote or book: independent (+30, or +15 when partly self-released), 1k to 100k followers or monthly listeners (+25), a release in the last 90 days (+20) or year (+10), an Instagram or TikTok account (+15), an e-mail address (+10). Results from each link or search are sorted by it, highest first, and Min lead score drops the rest.

Is this legal?

It reads public profile and catalogue pages anyone can open without an account. Use the data in line with the platform's terms and privacy law where you are, especially for e-mail outreach.

Do I need an account, API key or cookies?

No.

Why is a value empty?

Each platform shows different numbers, and some profiles leave fields blank. Missing values are null, so columns always line up.

Free plan?

Free-plan runs are limited to a small number of results per month. Paid plans have no limit.

How much does Music Artist Scraper cost?

$2.50 per 1,000, charged only for profiles returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Music Artist Scraper return?

Every row has the same fields, including platform, id, url, username, name, verified, independent, label, selfReleasedShare, aiArtist, followers, following, monthlyListeners, worldRank, trackCount, playlistCount, albumCount, singleCount, likesCount, city, country, bio, avatarUrl, headerImageUrl, gallery, links, socials, emails. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as find_music_artists.
