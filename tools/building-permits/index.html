Guide

How Building Permits Scraper works

Inputs, options and tips, from the tool's own documentation.

New building permits from US cities, in one format. Each permit comes with the work description, address, estimated project value, contractor and dates, read from the city's own official open-data table.

At a glance

  • Cities: Chicago, New York, Los Angeles, Austin, Seattle, Dallas, Kansas City, Cincinnati, New Orleans, Baton Rouge, Montgomery County (MD), Mesa and Honolulu. Any other city that publishes its permits on an open-data site: paste the table's address.
  • Filters: issued in the last N days, keywords (solar, roof, pool, demolition...), minimum project value, only permits that name a contractor.
  • Monitoring: turn on Only new since last run and put the run on a schedule to get each new permit once.
  • Price: $2 per 1,000 permits, plus a small start fee per run. Empty runs cost only the start fee.

Who uses it

  • Contractors and subcontractors looking for jobs that were just approved.
  • Suppliers of building materials, solar, roofing, HVAC, pools and equipment rental.
  • Real estate investors and insurers following construction activity by area.

Questions

Questions about Building Permits Scraper

How fresh is the data?

As fresh as the city's own table, usually updated daily.

Why do some permits have no contractor or value?

The city did not record one for that permit.

Is this personal data?

Permits are public records. Some name an owner or applicant; use them within the law that applies to you.

How much does Building Permits Scraper cost?

$2 per 1,000, charged only for permits returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Building Permits Scraper return?

Every row has the same fields, including city, issuedDate, permitType, description, address, estimatedValue, contractorName, permitNumber. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
