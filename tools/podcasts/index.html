Guide

How Podcast Scraper works

Inputs, options and tips, from the tool's own documentation.

Podcasts from Apple Podcasts search, top charts (any country, any genre) and links, enriched from each show's own RSS feed: owner name and contact email, website, language, categories, episode count, how often it posts and when it last did. Add the latest episodes with dates, durations, audio and transcript links.

Built for podcast booking and PR agencies pitching guests, advertisers and sponsorship teams, creators researching their niche, market researchers, and AI agents.

Why this Actor

  • Search, charts and links in one run; top charts for 19 genres in any Apple country.
  • Contacts from the source: the owner email publishers put in their own RSS feed.
  • Find active shows: filter by minimum episodes, posted in the last N days, language, with email only, no explicit.
  • New shows alerts: schedule a chart with Only new podcasts to catch shows entering it.
  • For AI agents. Callable as an MCP tool.

How to use it

Active US tech podcasts with a contact email:

json
{ "chartGenres": ["Technology", "Business"], "country": "us", "maxPerSource": 200, "withEmailOnly": true, "activeWithinDays": 30 }

Pricing

$4 per 1,000 podcasts and $1 per 1,000 episodes, plus a small start fee per run. On the Apify free plan a run returns up to 100 podcasts.

Good to know

  • Emails are those the podcast owner published in their feed for directories; use them for relevant, personal outreach and follow the law where you are (CAN-SPAM, GDPR).
  • A few feeds are offline or private; those podcasts still come with their Apple details and a feedError.

Questions

Questions about Podcast Scraper

How much does Podcast Scraper cost?

$4 per 1,000, charged only for podcasts returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Podcast Scraper return?

Every row has the same fields, including title, author, appleId, appleUrl, feedUrl, artwork, ownerName, ownerEmail, website, genre, genres, categories, language, explicit, country, episodeCount, firstEpisodeDate, lastEpisodeDate, averageDaysBetweenEpisodes, source, rank, Episodes: title, publishedAt, durationSeconds, episode, season, description, audioUrl, transcriptUrl. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as search_podcasts.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
