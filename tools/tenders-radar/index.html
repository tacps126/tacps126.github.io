Guide

How Tenders Radar works

Inputs, options and tips, from the tool's own documentation.

Public procurement notices from official government portals of many countries in one clean schema: open tenders you can bid on, contract awards (who won, for how much) and planned procurement. Filter by country, sector, CPV / UNSPSC code, value and keywords; schedule it for daily bid alerts.

Built for B2B sales and bid teams, contractors and consultancies, distributors, market researchers tracking public spending, and AI agents that find opportunities for their users.

Why this Actor

  • One schema for every country. title, description, reference, buyer, status, noticeType, category (works / goods / services), classifications (CPV, UNSPSC, NAICS, PSC), value (amount + currency), publishedAt, deadline, suppliers, contacts, documents, url.
  • Sectors in every language. Each notice is tagged from its CPV, UNSPSC, NAICS or PSC codes plus terms in English, French, Spanish, Portuguese, German, Dutch and Italian: IT & tech, construction, health, energy, transport, defence, environment, education, finance and more.
  • Only what you can bid on. By default you get open tenders whose deadline hasn't passed; switch on awards to see who wins what.
  • Daily bid alerts. Turn on Only new notices and schedule it: each run returns only what earlier runs didn't deliver. Send it to Slack, Google Sheets, a webhook or an RSS reader.
  • For AI agents. Callable as an MCP tool.

How to use it

  1. Pick sectors and/or countries (EU = every EU/EEA country) and, if you like, states or regions (searchable list, or type Texas, Maharashtra, Bavaria), or type keywords.
  2. Optionally add CPV / UNSPSC codes, a minimum value, or notice types (awards, planning).
  3. Press Start. For alerts, turn on Only new notices and add a daily schedule.
json
{
  "sectors": ["tech"],
  "countries": ["EU", "GB", "CA"],
  "minValue": 100000,
  "postedWithinDays": 3,
  "onlyNew": true
}

Keywords match literally, so add translations for non-English portals (software, logiciel, Software), or rely on sectors and codes, which work in every language.

Who wins what (supplier mode)

Put company names in Suppliers and the Actor lists the public contracts each one won, in the US (federal, USAspending), every EU/EEA country (TED) and the UK (Contracts Finder), over the last two years by default, with a summary per company first: number of awards, total value per currency, top buyers, first and last award, and the legal names the portals used (PALANTIR USG INC, Accenture (UK) Ltd...).

Use it to size a competitor's public-sector business, find which agencies buy what you sell, or check a supplier during due diligence.

json
{ "suppliers": ["Accenture", "Capita"], "countries": ["GB", "EU"], "awardedWithinDays": 365 }

Each award is billed like a notice; the summaries are free. Award values are as published: a notice with several winners shows its total for each.

AI insights (optional)

Turn on AI insights and an AI reads each notice for you: a two-sentence summary in your language, what is being bought, who may bid, the deadline and value as written, and what to do next. Describe your company in Your profile and every insight also gets a fit score (0-100) with the reason, so the best matches rise to the top. Choose "Apify (no key)" and the model's cost goes to your Apify account, or use your own Anthropic, OpenAI, Gemini or other key.

Good to know

Values are in each notice's own currency (no conversion yet). SAM.gov is read from its public daily extract (no key), so US notices appear the morning after they are posted. Notices are copied as published and always link to the official notice; check the portal before bidding.

Questions

Questions about Tenders Radar

How much does Tenders Radar cost?

$4 per 1,000, charged only for tenders returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Tenders Radar return?

Every row has the same fields, including title, description, reference, buyer, contacts, country, subdivision, status, noticeType, category, procedure, classifications, sectors. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_supplier_contracts and search_tenders.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
