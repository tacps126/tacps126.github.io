Research Radar — Papers, Preprints & Patents

Search OpenAlex, arXiv, PubMed, Europe PMC and patents at once: one deduplicated, newest-first feed of papers and patents with abstracts, authors, DOIs and PDFs. Only-new alerts, RSS feed, optional AI summaries on your own key.

Build the input, get the call

Change any field; the code on the right follows. Copy it, or run the same input on Apify.

Keywords or phrases, one per line. Each is searched in every source you pick. Boolean operators (AND, OR, NOT) and quotes work in most sources.

Where to search. Results found in several sources are merged into one record (`foundIn` lists them).

Filters

Only results published in the last N days. Leave empty for any time.

Only results published on or after this date.

Only papers you can read for free (patents are always included).

Newest first suits alerts; the other two surface the most influential work.

Retracted papers are left out by default. Turn on to keep them (flagged `retracted`).

Most results each source returns for each query, before merging.

Most results delivered in total (after merging).

Monitoring

Schedule the Actor and each run returns only papers and patents earlier runs didn't deliver — a research alert you pay for only when something new appears.

AI (your own key)

Add a short plain-language summary to each result, written by the AI model of your choice on your own API key (you pay your provider directly; nothing extra here).

e.g. English, German, Japanese. Default English.

Translate each query into these languages (e.g. de, fr, zh, ja) with your AI key and search those too — finds work published in other languages.

curl -X POST \

Python · pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("tacps126/research-radar").call(run_input={
    "queries": ["solid state battery"],
    "postedWithinDays": 30,
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)
JavaScript · npm i apify-client
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });
const run = await client.actor('tacps126/research-radar').call({
  "queries": [
    "solid state battery"
  ],
  "postedWithinDays": 30
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

What you get back

The fields every row has.

FieldWhat it holds
typepaper, preprint or patent
title, abstractAs published
authors[{name, affiliation, orcid, country}] when the source has them
publishedAtPublication date (YYYY-MM-DD)
venueJournal, server (arXiv) or repository
doi, url, pdfUrlIdentifiers and links (PDF when openly available)
openAccess, citations, language, keywordsWhen known
citationsPerYearCitations divided by years since publication
fieldNormalizedImpact, citationRankImpact against papers of the same field and year (1.0 = average); top 1% / top 10%
retractedtrue for retracted papers (only with Include retracted)
idsopenalex, pmid, pmcid, arxiv, europepmc
patentFor patents: number, kind, country, familyId, applicationNumber, filingDate, priorityDate, classifications (IPC), applicants
foundInEvery source that returned it
query, matchedQuery, queryLanguageWhich of your queries found it (and the translation, for multilingual search)
aiSummaryWith AI summaries on
