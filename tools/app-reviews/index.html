App Store & Google Play Reviews Scraper

Scrape app reviews from the Apple App Store and Google Play in one dataset: rating, text, author, date, app version, developer replies — plus sentiment, reply time and app rating summary. Multiple countries, star filters, new-review monitoring.

Try it

Build the input, get the call

Change any field; the code on the right follows. Copy it, or run the same input on Apify.

App Store or Google Play links, one per line. App Store ids (`id324684580`) and Android package names (`com.spotify.music`) work too. Mix both stores freely.

2-letter store countries, e.g. `us`, `gb`, `de`, `in`. App Store reviews are separate per country, so each country adds reviews. Google Play uses the first one.

2-letter language codes for Google Play reviews, e.g. `en`, `de`, `es`. Each language adds its own reviews.

Which reviews to get first.

Keep only reviews with these star ratings, e.g. 1 and 2 for complaints. Leave empty for all.

Only reviews written on or after this date. With “Newest first”, the Actor stops reading once it passes this date.

Keep only reviews whose title or text mentions any of these, e.g. `crash`, `login`, `price`.

Drop reviews whose title or text mentions any of these.

Keep all reviews, only those the developer answered, or only unanswered ones (developer replies are available for Google Play).

Skip very short reviews (characters).

Maximum reviews per app (per country for the App Store).

Maximum reviews in total.

Monitoring

Return only reviews that no earlier run with the same input has delivered — for daily review alerts. You pay only for new reviews.

curl -X POST \
  "https://api.apify.com/v2/acts/tacps126~app-reviews/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"apps":["https://apps.apple.com/us/app/spotify-music-and-podcasts/id324684580","https://play.google.com/store/apps/details?id=com.spotify.music"],"countries":["us","gb"],"language":["en"],"sort":"newest","starRatings":["1","2"],"maxReviewsPerApp":500}'

for item in client.dataset(run["defaultDatasetId"]).iterate_items():
