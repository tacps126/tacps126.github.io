Guide

How Facebook Pages Scraper works

Inputs, options and tips, from the tool's own documentation.

Get Facebook page details as clean rows: name, categories, email, phone, address, website, social links, followers, likes, rating and reviews count, price range, services, verified badge, profile and cover photos. Paste page names or links and press Start. No login, no cookies, nothing to install.

How to use

  1. Add page names (starbucks) or links (facebook.com/katzsdeli, facebook.com/profile.php?id=...) under Pages.
  2. Press Start. Download the results as JSON, CSV or Excel, or send them to a webhook or Google Sheets.

The Contacts view shows only name, email, phone, address, websites and social links, ready for a lead list.

  "pages": ["katzsdeli", "https://www.facebook.com/starbucks"]

Good to know

  • Only public data is read: fields a page does not show come back empty.
  • Follower and like counts are rounded the way Facebook shows them (158K becomes 158000).
  • Photo links expire after a few days; download the files if you need to keep them.
Questions

Questions about Facebook Pages Scraper

Do I need a Facebook account?

No.

Does it read posts?

No, it reads page details. Use it to build lead lists or enrich a list of businesses.

How much does Facebook Pages Scraper cost?

$3 per 1,000, charged only for pages returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does Facebook Pages Scraper return?

Every row has the same fields, including name, url, pageId, categories, email, phone, address, websites, socialLinks, followers, likes, following, recommendPercent, reviewsCount, priceRange, services, hoursStatus, verified, profilePicUrl, coverPhotoUrl. Download as JSON, CSV, Excel or XML.

Can an AI agent use it?

Yes. The webdata-tools-mcp server exposes it to Claude, Cursor and other MCP clients as get_facebook_pages.
