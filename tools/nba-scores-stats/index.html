Monitoring

Schedule the Actor and each run returns only what earlier runs did not deliver. A game comes again when its status changes (scheduled, live, final), so a daily run with Game status = Final gives each result once.

Guide

How NBA Scores, Box Scores & Stats works

Inputs, options and tips, from the tool's own documentation.

NBA scores and schedules, player box scores, standings, teams and rosters with injury status, plus the WNBA and NCAA men's basketball (all Division I teams). Pick dates and teams, export to JSON, CSV or Excel, or schedule it to get each final once.

Built for fantasy and DFS players, bettors and prop modellers, basketball analysts and writers, newsletters and Discord bots, and AI agents.

How to use it

Last night's NBA results:

json
{ "leagues": ["nba"], "daysBack": 1, "gameStatus": "final" }

Lakers and Celtics player lines this month:

json
{ "leagues": ["nba"], "dataType": "boxScores", "dateFrom": "2026-10-01", "teams": ["Lakers", "BOS"] }

Tonight's and tomorrow's schedule:

json
{ "leagues": ["nba"], "daysBack": 0, "daysAhead": 1, "gameStatus": "scheduled" }

Opening and current betting lines for the next games:

json
{ "leagues": ["nba"], "dataType": "odds", "daysBack": 0, "daysAhead": 1 }

Options

OptionWhat it does
Leagues (leagues)nba, wnba, ncaab
Data (dataType)games, boxScores, odds, standings, teams or rosters
Days back / Days ahead (daysBack, daysAhead)Rolling window: daysBack: 1 = yesterday and today; daysAhead: 7 = next week's fixtures

Game status (gameStatus)any, final, live or scheduled
Teams (teams)Names or abbreviations, e.g. Lakers, BOS. Empty = all
Season (season)Standings for a past season, e.g. 2025 (the 2024-25 season); empty = current
Max results (maxItems)Most rows per run
Only new (onlyNew, monitorName)With a schedule, each run returns only rows earlier runs did not deliver; a game comes again when its status changes

Pricing

$3 per 1,000 games, odds rows, standings rows, teams or players, and $1 per 1,000 box-score player lines (an NBA game is about 26 lines, so about 3 cents), plus a small start fee per run. On the Apify free plan a run returns up to 100 rows.

Good to know

  • Dates follow the US game day: a 10:30 pm Eastern tip-off on October 29 counts as October 29.
  • Only new + a daily schedule returns each game again only when its status changes, so finals arrive once.

Questions

Questions about NBA Scores, Box Scores & Stats

How much does NBA Scores, Box Scores & Stats cost?

$3 per 1,000, charged only for game, standing, team or players returned; a run that finds nothing costs nothing. It runs on Apify, whose free plan includes monthly credit, so you can try it without paying.

Do I need to write code?

No. Fill in the form on Apify and press Start, schedule it, or send the results to Google Sheets, Slack or a webhook. For code, the input builder on this page writes the API call in curl, Python or JavaScript.

What does NBA Scores, Box Scores & Stats return?

Every row has the same fields, including Games, Box scores, Odds, Standings, Teams / rosters. Download as JSON, CSV, Excel or XML.

Can it run on a schedule and return only new results?

Yes. Schedule it on Apify (hourly, daily, weekly) and turn on the only-new option: each run then returns only what appeared since the last run with the same input.
