FAQ
Before you start

    

      
How do I try a tool?
Open its page here to see the input and output, then press Run it on Apify. Apify's free plan includes monthly credit, enough to try every tool on real data.

      
What does it cost?
You pay per result: from $0.40 per 1,000, most tools $1-$3, and a few optional extras such as AI insights (see pricing). Searches that find nothing are not charged, and every run can be capped at a spend limit you set.

      
How do I call it from code?
Every tool is an HTTP endpoint: send the input, get the rows back as JSON, CSV, Excel or XML. Each tool page writes the call for the input you build, in curl, Python and JavaScript. Ready-made scripts are in the recipes.

      
What happens when a website changes?
The tools are run against their live sources on a schedule. When a site changes, the tool is fixed and a note goes into its changelog.

      
Can it read pages behind a login or a captcha?
No. The tools read public pages only and never solve captchas. A few accept your own sign-in for pages your account can see, and say plainly when a source is closed.
