Built to be fast and cheap to run

The tools are small native programs, not heavy browser scripts. A typical run costs a fraction of a cent in platform usage, so the price you see is the price you pay.

Rust, no browser by default

Single static binaries that start instantly and run in 256 MB. A browser is used only where a site needs one.

Pay per result

About $1 per 1,000 results for most tools. Where nothing is found you are not charged, and you can cap spend per run.

Only new, on a schedule

Turn on only-new mode and each scheduled run returns just what changed, so alerts and feeds stay cheap.

Careful with limits

Rate limits are respected, failed requests are retried, and runs resume without charging twice.
