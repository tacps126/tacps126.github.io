MCP server

Web data tools for your AI agent

webdata-tools-mcp gives Claude, Cursor and any MCP client 32 typed tools for jobs, hiring signals, news, research papers and patents, field trends and idea validation, reviews, Reddit, contacts, property, Shopify, trade shows and events, plus two analyst prompts. They run ready-made Apify Actors on your own Apify account and return clean, short results.

Install in two minutes

Install in two minutes

You need Node.js 18+ and a free Apify account. Copy your API token from Apify Console → Settings → API & Integrations.

terminal
claude mcp add webdata -e APIFY_TOKEN=<your Apify token> -- npx -y webdata-tools-mcp
claude_desktop_config.json
{
  "mcpServers": {
    "webdata": {
      "command": "npx",
      "args": ["-y", "webdata-tools-mcp"],
      "env": { "APIFY_TOKEN": "<your Apify token>" }
    }
  }
}
mcp.json
{
  "mcpServers": {
    "webdata": {
      "command": "npx",
      "args": ["-y", "webdata-tools-mcp"],
      "env": { "APIFY_TOKEN": "<your Apify token>" }
    }
  }
}

Prefer no install? Apify's hosted server works too: https://mcp.apify.com?tools=tacps126/google-news,tacps126/hiring-signals (it signs in with OAuth; its tools take each Actor's raw input fields).

Try asking

Try asking

"Which of these companies are hiring data engineers right now? boards.greenhouse.io/stripe, jobs.lever.co/spotify"

"Show the 1 and 2 star Trustpilot reviews of example.com from the last 30 days and group the complaints."

"Find news from the last 7 days about open-source LLM licensing, with the real publisher links."

"What does a 2-room flat in Berlin cost to rent right now? Give me the cheapest ten with coordinates."

"What should a seed-stage founder build in sodium-ion batteries? Compare it with solid-state." (the field-opportunity-analysis prompt)

"Is a drone that plants trees a new idea? Who is already working on it?" (the idea-validation prompt)

Two ready-made prompts, field-opportunity-analysis and idea-validation, turn the research tools into an innovation analyst with the same rubric for any model. Agents that load skills can use skills/innovation-analyst.

Safe by design

Safe by design

Spend cap per call

Every call is capped at $0.50 by default (WEBDATA_MAX_CHARGE_USD). Apify stops the run when it is reached.

Read-only tools

All tools only read public web data and are marked read-only, so clients can run them without extra prompts.

Short, structured results

Results come back as text and as structured content. Long fields are shortened and one result is limited to about 60,000 characters.

Your account, your token

The server talks only to Apify. Your token stays in your own configuration and runs bill to your own Apify account.

Questions

Questions

What does it cost?

The server is free and MIT licensed. Each tool bills the Apify pay-per-result price shown above to your own Apify account (about $1 to $3 per 1,000 results). Apify's free plan includes monthly credit to try it.

Where does my API token go?

Into the environment of the server process on your machine. It is sent only to Apify's API to run the Actors. It is not logged or sent anywhere else.

Can I change the limits?

Yes: WEBDATA_MAX_CHARGE_USD (spend cap per call, default 0.5) and WEBDATA_TIMEOUT_SECS (how long one call may run, default 150, from 30 to 300).

Is it legal to use the data?

The Actors read publicly available pages. You are responsible for following each site's terms and the law that applies to you (for example GDPR and CAN-SPAM), especially for contact details.

Where is it listed?

On npm, in the official MCP Registry as io.github.tacps126/webdata-tools-mcp, on Smithery, Glama and MCPRush. Claude Desktop users can install the one-click bundle from the latest release.
